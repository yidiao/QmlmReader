## 技术路线（三选一 · ⬜ 待所有者裁定）

| 路线 | 说明 | 优 | 劣 |
|---|---|---|---|
| A 纯 AI 重绘 | 图生图 API（GPT-image 类；**DeepSeek 无图像 API**，需另接服务商） | 语义级重绘，贴设计稿原意 | 单张成本、key 管理、结果不可复现；「吃透 AI 重绘」是前置条件 |
| B 纯本地 canvas | 色阶 posterize 映射宣传画色板（红/黑/米）+ 半调颗粒 + 阈值剪纸化 | 零 API 零成本、即时预览、离线可用、**输出确定性可复现**（供图刚需） | 只有像素级风格化，无语义重绘（如剪纸轮廓化） |
| C 混合（建议） | 先 B 落地 MVP——设计稿四滑块（红调强度/版画颗粒/剪纸化/对比度）天然就是本地处理参数；AI 重绘后续作「AI 冲印」按钮叠加进同一 UI | UI 不返工、先出可用工具、供图可复现 | 分两期，AI 期仍需选型 |

**补充约束**：

- 联动供图（青马敌人立绘、小册子插图）要求数字可复现 → 本地路线天然满足，AI 路线需固定种子/参数。
- 新页面/重构页须带暗色模式防 FOUC 内联脚本（2026-11-07 全站约定）。
- 保留母站骨架：公共导航、暗色模式、正确相对路径（`doc/design-tokens.md` §12 视觉豁免条款）。

## 决策点

- ⬜ 路线 A / B / C 选定
- ⬜ 若含 AI 期：图像 API 服务商选型与成本口径
- ⬜ 联动供图时机：建议各接收端（青马/小册子）竣工后再接
