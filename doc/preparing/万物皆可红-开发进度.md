# 万物皆可红 — 开发进度

> 设计稿（档案区，不随进度改写）：[../pages/experimental/research/万物皆可红/万物皆可红-设计文档.md](../pages/experimental/research/万物皆可红/万物皆可红-设计文档.md)

## 产品定案（2026-11-08 所有者拍板）

- **体验基调**：一键相机式——上传 → 选流派×原型 → 一键生成 → 分享卡；不搞调参工作台（设计稿的滑块降级为可选"冲印微调"，v1 可不做）。
- **化身型（原 A 路线）**：照片主体被替换为宣传画原型，不是保留人脸的风格化滤镜。
- **原型库双分支**：人物原型（工人/社员/战士/少先队员……）＋ **场景原型**（城头红旗、楼上条幅等经典构图意象——出整幅海报而非头像特写）。
- **谱系研究三派先行**：中国工农兵宣传画（哈琼文、钱大昕一路）、延安木刻版画、苏联构成主义（罗钦科一路）。研究卡落 `research/万物皆可红/`，方法论沿用样板戏"逐部研究→蒸馏 Prompt"。
- **灵感源修正记录**：产品本质 = AI 相机（身份替换体验），AI 重绘是本体；2026-11-07 曾建议的"本地 canvas 先行"作废（做不出"化身"），路线 B 纯本地出局。
- **分享闭环**：沿用母站分享卡经验（画框＋印章＋二维码），具体细节见技术层工程件⑤。

## 立意定案（2026-11-08 第二轮讨论）："万物皆有劳动者"

- **核心立意：劳动者显形**——照片场景"召唤"它背后隐藏的劳动者，以宣传画美学塑成英雄。拍垃圾桶 → 环卫工被画成劳模；拍外卖箱 → 骑手成延安木刻英雄；拍灶台 → 炊事员。**物件不是被装饰，而是被它背后隐藏的劳动激活**——正面回答"单个物件难以立意"的问题。
- **格式对照**：奶龙 = 角色入侵场景（笑点 = 违和）；我们 = 劳动者显形（点 = 看见 + 尊严）。宣传画的原始功能本就是"把普通劳动者塑造成英雄"，此立意是回到形式本体，而非往格式上贴内容。
- **与化身型的关系**：主体替换为原型 = 替换为劳动者原型；人物线与场景线并轨于同一立意（场景线 = 劳动者被组织进整幅海报构图，城头红旗/楼上条幅类）。
- **原型库组织原则**：`流派 × 劳动者类型`——现代职业 × 经典画法，反差即传播力，尊严即立意。
- **四候选裁定**：
  - 画符号 ❌——符号脱离劳动语境即贴纸，且有消解（梗图化消费）与戏谑两种坏读法；
  - 换画风 → 降级为附加模式（"样式"不是"说法"）；
  - 放劳动者 ✅ **核心立意**；
  - 东欧剧变未发生的遐想 → **剥离为独立展览线**（推演型创作，不依赖用户照片，与相机分立；可接 puzzle 展览模块的既有传统），不作相机立意。
- **站内一致性**："劳动可见化"与马克思主义阅读站的全站气质一致。

## 技术路线（2026-11-08 收敛）

> **裁定**：产品内核 = AI 重绘（灵感源即 AI 相机，化身体验本地滤镜做不出）——路线 B「纯本地」出局，原「C 混合先行」建议作废。AI 路线需自行解决输出确定性（供图联动刚需）。下表留档旧分析：

| 路线 | 说明 | 优 | 劣 |
|---|---|---|---|
| A 纯 AI 重绘 | 图生图 API（**DeepSeek 无图像 API**，需另接服务商） | 语义级重绘 | 成本、key 管理、可复现性——均转入技术层解法 |

## 技术层方案（2026-11-08 成文）

### 管线（与奶龙相机同类，已验证为大模型整图重绘）

```
选原型卡(流派×劳动者) → 上传照片(前端压缩) → 图像编辑 API(照片+prompt卡) → 成图预览 → 分享卡导出
```

- **完全依赖图像编辑大模型**（图生图/指令编辑），无本地合成管线。证据（奶龙截图核验，2026-11-08）：屏幕 UI 文案被重新渲染（"板烧鸡腿堡套餐"→"奶龙补给套餐"，贴图合成做不到）、主体遮挡与光影同原场景一致（条件整图生成）。
- 前端零 GPU 需求，GitHub Pages 静态托管兼容。

### 图像 API 候选（⬜ 选型：同一组测试照片 × 同一 prompt 卡实测后定）

| 候选 | 接入 | 优势 | 疑点 |
|---|---|---|---|
| Gemini nano banana（`gemini-3-pro-image-preview`） | Google AI Studio | 梗图相机类代表底座；角色一致性（至多 4 角色 10 物体）；指令遵循强 | 国内网络门槛；美元计费 |
| 即梦 SeedEdit | 火山引擎 | 国内直连、人民币计费、中文指令友好 | 一致性/编辑力需实测 |
| 通义万相图像编辑 | 阿里云百炼 | 国内直连、文档全 | 同上 |

- **测试口径**：人像/物/景各一张 × 三派 prompt 卡各一 → 比化身体现、文字渲染质量、单张成本 × 预估重试率。

### 关键工程件

1. **原型 prompt 卡体系**：`流派 × 劳动者类型` → prompt 模板（画派锚定描述 + 构图指令 + 限色板 + 负面项）；`research/` 谱系研究卡是 prompt 卡的母本，prompt 卡是研究卡的蒸馏产物（沿用样板戏管线）。
   - 示例（环卫工 × 延安木刻）：黑白木刻风格，粗刀痕，强黑白对比，画面主体为一名正在清运垃圾的环卫工人，仰视纪念碑式构图，身后光芒线……负面：彩色、照片质感、真实政治人物、国徽党徽。
2. **输出确定性**：每次生成的 seed/参数随图记录导出；供图联动时按参数复现。
3. **key 通道**：v1 沿用 LS 自带 key；公开部署前迁统一代理（工程牌「跨工具事项」）。
4. **隐私口径（建议稿，待所有者确认）**：上传前明示"照片将发送至所选 API 服务商处理"；不落库、即用即弃，本地不留存原图与成图（分享卡由用户主动导出）。
5. **分享卡**：复用母站经验（画框 + 印章 + 二维码），Canvas 导出 PNG（马列体已有 canvas 分享卡成例可参照）。

### 风险登记

- **版权**：风格不受版权保护，但具体画作是作品/文物——prompt 卡只描述风格特征与限色板，**不以具体画作图片作参考图**（除非确认公版）。
- **敏感**：劳动者 × 政治美学组合，负面 prompt 硬约束：真实政治人物形象、国徽党徽规避；沿用全站安全加固口径。
- **成本**：单张计费 + 失败重试；v1 用户自带 key 成本自负，接统一代理后再议限额。
