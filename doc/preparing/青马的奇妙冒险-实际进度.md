## 定位

文字选项小游戏。玩家扮演坚持马列主义的「青马」，与互联网上「自以为正确」的错误思想原型对战，辩倒敌人闯关胜利，辩不过就被错误思想吞噬。

在闭环中承担「学习——批判性思维训练」。

视觉继承母站红金黑构成主义，共享母站骨架（导航 / 暗色模式 / 自定义光标）。

## 三属性

- **理论信心 / 辩证力 / 阶级觉悟**
- 上限 **20**；开局三项各 **5–10** 浮动、**总和固定 24**
- 单项 **> 15** → 免除困难档「0 伤倒扣 1 HP」debuff
- 常规选项按属性类型受属性过低影响，感性攻击不受自身属性影响

## 伤害与难度

- 普通选项伤害上限 **3**；杀招 / 特殊选项可突破至更高
- 每局从题库抽 **30 题**
- 难度三档：
  - 第 **1–10 题**：基础
  - 第 **11–20 题**：中等，普通怪/精英/BOSS 血量增加
  - 第 **21–30 题**：困难，默认 **-1 伤害**，0 伤可能倒扣 1 HP
- 普通怪基础 2 血；精英怪基础 5 血；BOSS 基础 8 血

## BOSS 战（三段论证）

- 每 10 题后进入 1 关 BOSS，共 3 关
- BOSS 姿态：**攻 / 守 / 挑衅**
- 玩家按「论点 → 论据 → 反击」三段论证拆招/搓招
- 击败 BOSS 后进入商店
- BOSS 池已按三关配置：如酚鬣/姜太公/旺座小鬼/鳗衣等

## 杀招

- 已实装 4 个杀招：理论碾压、归谬杀招、阶级审判、背水一战
- 有属性门槛、精准打击次数、共享冷却、副作用等机制
- 击败 BOSS 后可在商店解锁

## 图鉴与特殊能力

- 敌人图鉴、事件图鉴均已实装
- 敌人特殊能力包括：弱点增伤、自愈、吸血、封印选项、亡语、属性动摇等
- 教化机制：满足阶级觉悟条件时可争取部分敌人

## 事件

- 正面事件、负面事件、商店事件、选敌事件均已实装
- 事件可影响属性、道具、遭遇阵营、精英次数、道具禁用、属性上限等

## DLC 与自制内容

- DLC 简答题模式：玩家手写答案，DeepSeek API 裁判评分
- 自制题：玩家可提交自定义题目，进入本地题库
- 当前 DLC 的 API Key 由用户在页面填写，后续建议迁移到 Vercel 代理

## 全流程

```
标题屏 → 战斗(30 题 + 3 BOSS 关) → 结算
  ├ 题 1–10  → BOSS① → 商店
  ├ 题 11–20 → BOSS② → 商店
  ├ 题 21–30 → BOSS③ → 结算
  ├ 敌人图鉴 / 事件图鉴 / 测试台
  └ DLC 简答题模式（AI 裁判）
```
