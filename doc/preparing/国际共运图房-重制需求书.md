## 0. 一句话目标

`html/international/international.html` = 一间"图房"：**真实世界地图铺满整个视口并横向无缝环绕**（HOI4 式），一切 UI 是浮在地图上的可折叠/可拖动悬浮件——读得清、关得掉、不挡地图。此页面是 index.html 主页重置的练兵场，框架必须可换内容复用。

## 1. 铁律（用户已拍板，不可协商）

1. **地图铺满全部画幅 + 横向环绕**：平移越过东西边界后丝滑接回另一边界（用户原话"我已经讲第三遍了"）。上下不环绕。当前实现只是 fixed svg 平移，无环绕——必须实现。
2. **站点导航 = 硬上边界**：地图显示区与一切 HUD 的定位/位移都不得高于站头底边。测量 `.site-header` 高度写入 `--masthead-h`（现机制已有，但站牌拖拽夹取、封面、抽屉等未全部遵守）。
3. **玻璃拟态只用于轻量悬浮件**（顶栏、站牌、控制条）；**一切阅读面（右侧抽屉、左侧详情、导览解说条）用实底 + 高对比文字**。浅色玻璃叠深色地图 = 浑浊中灰底，是上一轮事故根源。
4. **亮/暗双主题下每一个 HUD 面都要真实校验对比度**，两种模式都要人工看（上一轮深浅文字同色是事故，见 BUG-2）。
5. **解释性文字零容忍**：状态计数、操作提示、说明句一律不上屏（用户命令级要求）。atlas 原生写入的计数器元素保留为 hidden 即可。
6. **关闭是完备交互**：每个浮层有显式关闭钮；单击空白海面关闭一切浮层；Esc 兜底；**关闭即清 URL 参数**，刷新不得复活任何被关掉的东西。
7. **封面只首访一次**：localStorage 频控；且 HTML 默认渲染为隐藏、首访才显示（当前实现反过来——每次刷新先闪一下再消失，事故）。
8. **站牌钉具体地理坐标**（日历→彼得格勒 30.3,59.9；专栏→延安 109.5,36.6；时事→巴黎 2.35,48.85；纪念→柏林 13.4,52.5），引导线只画视口内且距离合理的；站牌默认位置互不重叠；**位置存储键带版本号，且不得继承调试期残留**（上一轮我的 QA 拖拽位置污染了用户布局，事故）。
9. **南海诸岛附图只在选中中国时出现**（注意字符串陷阱：`"中华人民共和国".indexOf('中国') === -1`，必须 `/中华人民共和国|中国/.test()`）。
10. **朋友图志（international-communist-atlas-main）的默认设定存在一眼错**（用户原话"各种一眼错"），默认截面、阵营设定**不要照抄**，采用前需独立审校。

## 2. 页面结构（目标态）

- 站点原生导航（`.site-header`，由 js/main.js 注入）保留最顶，其下才是图房视口。
- 全幅地图：图志数据管线（world-50m.json 212 国 + data/international/atlas.json 24 截面 + 中国 1949 固定红）+ 横向环绕。
- 顶栏工具栏（可拖/可折叠胶囊）：**面包屑用真链接接入站点体系**（不是装饰性 span）+ `/` 全文查找 + 视图切换 + 导览/图例/暗色/关于。
- **主从时间轴**：第一行 = 六个时代（语义名如"革命、建党与反法西斯"+年份，点击 = 选中时代并联动 atlas 时代筛选）；第二行 = **只列所选时代的截面**（第一行的细化）。已知设计问题：常驻通栏挡地图交互（见 BUG-7），形态需给用户过方案（候选：可收起/悬浮化/紧凑化）。
- 四张站牌（日历/专栏/时事/纪念）→ 各自档案抽屉；抽屉内容单一数据源：时事/纪念 **fetch 提取子页**（international-current.html / international-memorial.html 的 .news-item / .memorial-card），日历由 data/history-events.js（641 条）实时构建，专栏为固定目录卡。
- **图志检索室**（宽抽屉）：收编 atlas 原生筛选/结果/时代导读/逐国沿革/专题/来源。**信息架构待重定**：用户批评"又不像搜索又不像仓库"——需要明确身份（建议定位为"图志资料库"），"方法与来源"应是独立清爽视图。
- 左侧地图详情面板：点国别/标点出现；**显隐机制必须重写**（见 BUG-1）；× 与空白海面均可关闭。
- 导览：7 站镜头巡航+解说（flyToLL 已有），地图未就绪时优雅降级（当前报错，见 BUG-4）。

## 4. 已知 BUG 与诊断（按优先级）

**BUG-1 左详情面板：点国家不出现 / 关不上 / 左缘像素残条**（用户最愤怒项，根因未定位）
症状：点击国家后面板不滑出，仅左缘一点白/黑像素；此前版本关不上、刷新复活。
处方：放弃 MutationObserver 猜测式显隐——在 `onDraw` 钩子里轮询 `getState()` 的 `map.state` 与 `current.entry` 驱动显隐（state 驱动而非 DOM 突变驱动），关闭 = `clearSelection()`（钩子已有）。实现后必须实测：点国家→出现；×→消失；空白海面→消失；带 `?state=CHN` 刷新→出现；无参数刷新→不出现。

**BUG-2 暗色模式下抽屉浅底浅字**（根因已定位，一行修复级）
`--surface` 全项目**无定义**，`var(--surface,#fffdf7)` 永远落浅色回退；暗色下文字色又翻成浅色 → 浅底浅字。处方：`.canvas-root` 显式定义 `--surface`（浅 #fffdf7 / 暗 #132430）与文字令牌，全 HUD 面禁止裸回退色。

**BUG-3 站牌重叠 + 引导线乱标**（根因已定位）
存储键无版本 + restorePositions 无条件继承——上一会话 QA 拖拽位置污染用户布局。处方：键改 `qmlm:canvas:stations:v2` 并在布局大改时作废旧键；恢复时校验位置不与其他站牌重叠。

**BUG-4 导览报错**（未定位）
复现路径：顶栏"导览"或封面"跟随导览参观"。处方：地图未就绪时禁用入口；逐 TOUR 步骤断点实测；flyToLL 空守卫已有但需复查。

**BUG-5 刷新封面闪现**（根因已定位）
HTML 默认可见、JS 后隐藏 → 先闪后消。处方：默认渲染为隐藏，仅 `!seen` 时显示；hideCover 时写 `qmlm:canvas:seen`。

**BUG-6 地图无横向环绕**（铁律 1，未实现）
处方：地图分层（land/boundaries/markers/labels）渲染 ±1 个世界宽度副本，相机 pan.x 对世界宽度取模。与 atlas 现有 zoom/pan 机制（drawMap 内 scene transform）兼容性需先验证。

**BUG-7 时间轴挡地图交互**（设计问题）
常驻 96-112px 通栏限制地图。处理：先给用户 2-3 个形态方案再动手。

## 6. 工作方式（上一轮的教训写成纪律）

1. **一次只修一个，修完当场在浏览器验证再下一个**——上一轮"改一个问题出两个问题"就是这么来的。
2. 每个修复先陈述根因假设，被验证推翻就明说，不硬修。
3. 亮/暗 × 宽/窄四组合同测；用独立标签页验证，不与用户正在操作的标签页抢指针。
4. 纯静态、无构建步骤；改动全部留在本地，不 commit。
5. 给用户的截图只能作为辅助，**以用户实际上手为准**——上一轮截图漂亮上手崩坏的教训。
