## 立意定案（2026-11-08 所有者拍板）

- **核心表述**：**写作已经民主化，出版发行还没有。**（所有者定稿；发行含线上线下双途径，应用场景多）
- **历史配方**：每个时代的新思想 = 当时最新的媒介 × 专门研究过的美学。二十世纪初活动者把"形式"当理论工作的一部分来研究（《新青年》版式、陈望道译本红封面、《火星报》的经营），**形式即武器**；其吸引力美学大半是约束的产物——粗纸养出木刻标题、蜡纸油印养出地下刊物笔触、双色油墨养出套印节奏。
- **体裁自觉**：小册子（pamphlet）本身是有光荣史的体裁——《共产党宣言》《怎么办》都是小册子；**线下传阅是其原生复活场景**。
- **工具角色**：把那套"专门研究过"的宣传美学做成一键服务 = **新时代的流动排版车间**。
- **愿景**：结合马列体生成器与未来辅助套件，**一个人就是一个小报社**——个人出版链：写作（马列体）、美术（redify 供图）、装帧（小册子）、发行（分享卡/打印传阅）。
- **双发行路径**：线下 = 打印装订传阅物（**v1 主场景，A5 坚持不动**）；线上 = 屏幕卡片/长图（远期"分册"模式候选，不进 v1）。
- **远期扩展**：本地 DIY 与风格配置导入导出——文件级风格包（换配置文件 = 换风格），**非在线社区运营**；据此修订设计稿作废记录中"社区皮肤分享（P4）"的口径（P4 砍的是社区，文件级 DIY 与愿景相容，不属翻案）。
- **产品推论**：① **风格谱系研究化**——每个 preset = 一张研究卡（构图/字体/限色/纸感/纹样），与 redify 谱系库、样板戏八戏研究同一方法论，五工具统一"研究先行→蒸馏成资产"管线；② 阶段 3 AI 风格生成 = "给每个写作者配一个懂美术史的装帧师"，是立意的完全体（面板降级为微调）；③ 联动链（马列体→小册子）具有立意动机：写作→装帧。

## 路线（2026-11-08 立意后更新 · ①②③已裁定，④起待裁定）

1. **阶段 3 AI 装帧师（✅ 裁定：直冲）**：用户描述 → AI 吐整套风格 CSS；需约束沙箱（禁外部 URL、禁 `position:absolute` 等破坏分页的声明、限 `body[data-style]` 作用域）。立意完全体 = 给每个写作者配一个懂美术史的装帧师。
2. **阶段 2 面板降级为微调（✅ 裁定）**：AI 生成后调 `--paper/--ink/--accent` 等变量的微调条，不做完整调色工作台。
3. **风格谱系研究化（✅ 裁定：三派先行）**：新增 = 民国期刊、苏联构成主义书装、延安解放区出版物；现有「手作油印」「精致书刊」补溯源研究卡。研究卡落 `research/小册子/`，是风格 CSS 的母本。
4. **联动件**：马列体「对话录导出」→ 小册子导入——写作→装帧的个人出版链；建议两端竣工后再接（工程牌「跨工具事项」）。
5. **技术债**：mammoth / Google Fonts 走 CDN，离线/内网即挂（README 已登记）；可 vendor 本地化，升级版本前需回归。
6. **远期（不进 v1）**：屏幕「分册」模式（长图/连载卡片，线上发行场景）；本地 DIY 与风格配置导入导出（文件级风格包，非在线社区）。

## 决策点

- ⬜ CDN 依赖 vendor 本地化
- ⬜ 与马列体联动时机
- ⬜ 远期两项（屏幕分册、配置导入导出）是否登记 PLAN
