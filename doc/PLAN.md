> **性质**：产品层② 编辑计划。**只供项目所有者阅读与分派**；AI 接到任务后只负责执行并回来改状态格，不需要通读全表。
> 全局索引用 [README.md](README.md)；未竣工模块的进度在 [preparing/](preparing/)；过程知识与教训沉淀 [learnings.md](learnings.md)。
> 本文件是**干净表单**：完成 = 只改状态格；实施细节、踩坑记录一律不留在表内——出表进 learnings.md。

## 计划令牌（分类法）

**组判据**——每条任务必须归入且仅归入一个组：

| 组 | 判据 |
|---|---|
| A | 文档与事实同步（改文档本身、补索引、迁路径、知识提炼） |
| B | 令牌与约束治理（css 令牌体系、z-index、字体、断点） |
| C | 样式与页面收敛（页面/CSS 存量改造、内联治理） |
| D | 删除类决策（孤儿文件、遗留物处置） |
| E | 数据与方向性裁定（数据层、"做/不做"类决策） |
| F+ | 新域随时登记，登记后写入本表即为生效 |

**编号与状态规则**：
1. 编号只增不复用；新任务排入所属组的最小空号。
2. 状态机只有四种：⬜ 待办 ｜ 🔨 进行中 ｜ ✅ 完成（带日期）｜ 🔒 裁定结案（含"不做"决策，防重新讨论）。
3. 完成 = 只改状态格；备注格上限一句话。
4. 跨模块或涉公共层的任务入本表；模块私有小项写在模块 README，不入表。
