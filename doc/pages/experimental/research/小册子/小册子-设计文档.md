## 0. 定位

**一句话**：上传 Word，一键变红刊 PDF。

**核心价值**：让不懂设计的人，把普通文字一键变成"懂行"的红刊——不是撒一把红，而是符合手抄报 / 油印小报 / 书刊等真实美学传统。

**明确不做什么**：
- 不做文本编辑器——写作留在 Word，工具只管美化；
- 不做通用 PDF 工具——"美化"才是差异化，不是"排版"。

---

## 1. 最终架构（已落地）

```
上传 .docx → mammoth 解析 → 结构识别 → 分页渲染(A5) → 导出 PDF
```

- **Word 解析**：mammoth.js 把 .docx 转成结构化 HTML；
- **结构识别**：无标题样式也能识别（见 §2）；
- **结构**：封面 → 序言 → 目录 → 正文 → 尾页；
- **分页**：自写 JS，按内容高度把块切成 A5 页，每页**页眉（书名）+ 页脚（页码）**；
- **风格**：一套 CSS，`body[data-style]` 作用域，换风格 = 换一套 CSS；
- **持久化**：localStorage，刷新 / 重开不丢；
- **导出**：原生打印 `@page { size: A5 }`。

---

## 2. 结构识别规则

无标题样式的 Word（纯手工加粗 / 调字号）也能识别：

| 识别规则 | 映射到 |
|---------|--------|
| 第一个非空段 | 主标题 → 封面 + 页眉 |
| 以 `——` 开头的段 | 副标题 → 封面 |
| `引言/序言/前言/导言` 开头（及其后直到首个章标题） | 序言页 |
| `一、二、三、` 开头 | 章标题 → 目录一级 + 正文 h2 |
| `1.1 / 2.1` 开头 | 节标题 → 目录二级 + 正文 h3 |
| 其余 | 正文 |

> 启发式，覆盖最常见的无样式中文文档。换写法（如「第一章」、纯加粗无编号）可能漏判，规则可后续追加。

## 3. 风格系统

风格 = 一套 CSS，作用域 `body[data-style]`。当前两套：

| 风格 | 特征 |
|------|------|
| **手作油印** | 米白纸 `#f7f2e7` · 朱红标题 `#d4380d` · 虚线裁切框 · 楷体引用 · 群青批注 `#2f54a0` |
| **精致书刊** | 冷白纸 · 墨灰 · 细线 · 大留白 · 细衬线 |

颜色走 CSS 变量 `--paper / --ink / --accent / --accent2 / --line / --muted`，风格文件只覆盖这些变量 + 关键排版，结构全在底座。

---

## 4. 文件结构

```
html/experimental/xiaocezi.html    # 工具页
css/xiaocezi-style.css             # 底座：结构 + 分页 + 排版 + @page
css/xiaocezi-style-mimeo.css       # 风格：手作油印
css/xiaocezi-style-book.css        # 风格：精致书刊
js/xiaocezi/xiaocezi.js            # 核心：解析 + 分页 + 持久化
js/xiaocezi/style-engine.js        # 风格切换
```

纯前端零后端。CDN 依赖：mammoth（解析 docx）、Noto Serif SC（思源宋体）。
