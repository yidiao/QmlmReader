# experimental research 档案区

> **定性（2026-11-07）**：本目录是**研究档案区**——三层文档结构之外的资料归档，收录工具的设计规格、大纲、内容研究与美术资料。**进度类活文档已迁出**至 [../../../preparing/](../../../preparing/)（筹备与规划）。
> AI 默认不需要读取本目录全文；只有当任务明确涉及某个子工具的深层实现、文体提示、历史方案迁移时，才选择性读取相关文件。

---

## 1. 使用规则

1. 总览和模块 README 不复制本目录长文本。
2. 做普通页面维护时，不读本目录。
3. 做子工具功能修改时，先读 `doc/pages/experimental/README.md` 与 `doc/preparing/experimental-tools.md`（完成度工程牌），再选择性读本目录。
4. 涉及 Prompt 或生成策略时，只摘要工程结论，不在对话和总览里大段复述。
5. 过期研究稿可以直接覆盖为摘要或删除；可泛化的 UI/美术技巧提炼进 [../../../../learnings.md](../../../../learnings.md) 后原文即可归档。

## 3. 安全/误判规避口径

本目录含历史、文艺、实验工具、生成策略等研究材料。为了避免自动过滤误判：

- 对外汇报时优先称"experimental 子工具研究资料"。
- 不密集罗列原始文件标题。
- 不大段复制 Prompt、正文、描述性内容。
- 只抽取工程事实：路径、接口、状态、依赖、维护边界。
