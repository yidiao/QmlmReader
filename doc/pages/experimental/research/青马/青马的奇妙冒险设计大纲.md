## 定位

文字选项小游戏。玩家扮演坚持马列主义的「青马」，与互联网上「自以为正确」的错误思想原型对战，辩倒敌人闯关胜利，辩不过就被错误思想吞噬。

在闭环中承担「学习——批判性思维训练」。

视觉继承母站红金黑构成主义（与马列体同源），共享母站骨架（导航 / 暗色模式 `body.dark-mode` / 自定义光标）。

## 敌人谱系

| 阵营 | 成员 |
|------|------|
| 古董派 | 蝗旱、华钠、孔牢大 |
| 裂土派 | 酚鬣、蠹虫、鳗衣 |
| 外来派 | 牧田、美蜥鲂、蛇黾 |
| 闭目派 | 小粉红、剪纸、套中人 |
| 极左派 | 沱牌、旺座小鬼 |
| 虚无派 | 虚无主义者、姜太公 |

> 劳保（保守派）为计划敌人，未实装。敌人小故事（story）为用户手写，不改动。

## 三属性

- **理论信心 / 辩证力 / 阶级觉悟**
- 上限 **20**；开局三项各 **5–10** 浮动、**总和固定 24**
- 单项 **> 15** → 免除困难档「0 伤倒扣 1 HP」debuff（即主角成长）
- 三个常规选项各依赖一项属性，属性过低 → 伤害下降
- 感性攻击不受自身属性影响，通常输出不高

## 伤害与难度

- 普通选项造成 **0–3** 伤害；**杀招 / 特殊选项突破 3**（无上限钳制）
- 每局从题库抽 **30 题**（题库保留、越多越好，不砍题）
- 难度三档：
  - 第 **1–10 题**：基础
  - 第 **11–20 题**（中等）：只升血量——普通怪 **+1**、精英 **+2**、BOSS **+3**
  - 第 **21–30 题**（困难）：在中等基础上默认 **-1 伤害**；原本 0 伤的选项**倒扣自己 1 HP**
- 普通怪 2 血；精英怪至少 5 血；火力不足（≤2 伤害）被连环攻击

## BOSS 战（三段论证，专属）

- 独立于 30 题之外，每 10 题后进入，共 **3 关**
- 敌人三姿态：**攻 / 守 / 挑衅**（强化自身或弱化主角），**意图可见**
- 玩家需「拆招」+ 自己「搓招」（**论点 → 论据 → 反击**，攒满完整论证链触发杀招），同时提防对手拆招
- 血厚，能打 4–6 轮
- 3 个 BOSS 关从池中随机抽，各带专属称号：
  - ① 酚鬣 / 姜太公 / 旺座小鬼 / 鳗衣
  - ② 牧田 / 蠹虫 / 蛇黾 / 小粉红
  - ③ 美蜥鲂 / 套中人 / 剪纸 / 华钠 / 沱牌
- **击败 BOSS 后必定接一个商店**

## 杀招（build 体系）

- 在商店解锁，像「职业专精」一样挑选自己钟爱的几个特殊选项
- 解锁条件：如「**A 属性 > x 且 前 y 回合精准打击**」（与关系）
- 释放不消耗属性，但**冷却 z 回合，所有杀招共享冷却**
- 另有「条件简单但副作用大」的变体

## 图鉴与特殊能力

- 每个敌人有「**特点 + 特殊能力**」，**机械生效**，带惩罚面 + 奖励 / 反制面（不是单纯折磨）
- 「**教育**」机制（原「感化」改名）：条件满足时，蛇黾 / 小粉红等可争取敌人转化为同志并奖励主角
- 敌人小故事（story）为用户手写，不改动

## 事件

- **取舍事件为主、正面其次**；高收益与纯负面低概率
- 负面事件概率随难度上升
- 联动教育 / 属性 / 杀招 / 商店

## 动效

- 受击抖动、BOSS 打击反馈、大号伤害数字
- 克制，**不自动滚动**（滚动位置属于用户）

## 全流程

```
标题屏 → 战斗(30 题，3 难度档) → 结算
   ├ 题 1–10  → BOSS① → 商店
   ├ 题 11–20 → BOSS② → 商店
   └ 题 21–30 → BOSS③ → 结算
   └ 简答题模式 DLC（手写答案 → AI 裁判 → 评分）
```
