# 六维精读工艺（导师提炼方法）

> 用途：把一位导师的「文体模仿」升级为可复用、可核查的提炼流程。适用于新增导师、重写既有导师、以及把片段池从"裸引文"升级为"教学资产"。
>
> 来源：方法层借鉴 `karl-marx-skill`（MIT，© 2026 youaifuou），文本与数据全部按本项目场景重写。见仓库根 `THIRD_PARTY_NOTICES.md`。
>
> 适用对象：本项目的导师模块（`js/marxist/mentors/*.js`）与文章库（`article-db.js`）。

## 产出物总览

一轮完整精读应产出六份结构化材料，最终落到三个位置：

| 材料 | 落地位置 | 是否进 Prompt |
|---|---|---|
| 思想脉络 | `DOSSIER.timeline` / `epistemology` | 部分（按期注入） |
| 论战方法 | `DEBATE_FOUR_STEPS` 的实例化 + `DOSSIER.opponents` | 条件注入 |
| 表达 DNA | `periods[*].prompt` + `FRAGMENTS` | 是（主体） |
| 外部验证 | `DOSSIER.booklist` + `article-db` 篇目 | 否（选目依据） |
| 决策框架 | 危机/分歧时的判断规则 → 失效区与张力条目 | 是（少量） |
| 生平交叉 | 时期划分依据 | 间接（决定 period 边界） |

**纪律**：六维材料全部要有原文可指认的出处；无法落到具体文本的推断，只能进 `doc/` 研究笔记，不进 Prompt。

---

## 一、思想脉络（Chronology）

**问题**：这个人一生在解决哪几个问题？问题顺序如何变化？

**步骤**
1. 按写作时间排全部可获取文本（不是按"代表作"排）。
2. 标出问题转换点：同一概念在不同年份含义是否变化（如"国家"在 1848 与 1871 的含义差）。
3. 每个时期写 3 条以内"该时期的核心问题"，不要写评价。

**产出**：`DOSSIER.timeline`（每条：时间范围 / 核心文本 / 该期任务 / 对后续的影响，影响要写实质变化，不写抒情）。
**校验**：任一条 timeline 都能指出至少一篇对应文本；时间范围互不重叠且覆盖完整生涯。

## 二、论战方法（Polemic Method）

**问题**：他跟谁打、怎么打、打到什么程度收手？

**步骤**
1. 列出全部有名字的论敌（`DOSSIER.opponents`），按"同时代人 / 前人 / 阵营内部"分组。
2. 对每个论敌记一句"他实际针对的是对方的哪个论点"，而不是"他反对某人"。
3. 提炼 2-4 条可复用的拆解动作（先立最强版本→找前提→换概念→收网），写入 `DEBATE_FOUR_STEPS` 说明或导师 `prompt` 的论战段。
4. 标出**不适用场景**：没有明确论战对象时，论战段必须停用（对应 `INVALID_ZONE`）。

**产出**：`opponents` 9 条左右；论战四步法的导师化表述。
**校验**：每条论敌能对应至少一处原文；论战段在无对手输入时不触发。

## 三、表达 DNA（Expression DNA）

**问题**：去掉内容后，剩下的句式、节奏、修辞习惯是什么？

**步骤**
1. 统计可量化特征：句长分布、设问密度、枚举结构频次、感叹号密度、比喻密度、转折词偏好。样本量至少 5 篇、每篇 1000 字以上。
2. 提取 3-5 个**结构性**习惯（不是词汇偏好）：如"定义先行→枚举→自问自答→收网"、"二分法开题→俗谚落地→指向行动"。
3. 用这些习惯重写指定时期 `prompt`，每条习惯给一句可执行指令 + 一句反例（禁止写成什么样）。
4. 片段池：每段标注出处、时期、可迁移的句式特征（下一步升级为"学习要点"字段）。

**产出**：`periods[*].prompt`；`FRAGMENTS`。
**校验**：把 prompt 交给一个未见过的模型，能产出可辨认的句式；且不同时期输出可区分（用同题不同期对比）。

## 四、外部验证（External Check）

**问题**：哪些判断是学界共识，哪些是本项目自己的推断？

**步骤**
1. 书目：列可核查的中译本/原著版本与篇目（`DOSSIER.booklist`），作为 `article-db` 选目依据。
2. 对每条准备写进 Prompt 的风格判断，标注证据等级：**原文统计** / **学界通说** / **本项目推断**。
3. 只有前两级允许写成确定性指令；第三级必须写成"倾向"或放进 `TENSIONS`（承认不确定）。

**产出**：书目 + 证据等级标注（可放研究笔记）。
**校验**：随机抽 5 条 Prompt 指令，能说清依据等级。

## 五、决策框架（Decision Rules）

**问题**：遇到价值冲突、事实争议、私人情绪时，这个人的判断顺序是什么？

**步骤**
1. 从文本中找"他如何处理两难"的段落，抽象成 2-3 条优先级（如：阶级立场优先于程序正义 / 组织纪律优先于个人表达）。
2. 把优先级写成**边界规则**，进 `INVALID_ZONE` 或 `TENSIONS`：在什么问题上本框架不适用、在什么问题上必须承认矛盾。
3. 检查是否与产品底线冲突（攻击用户个人、替用户做政治表态、编造事实）——冲突时以产品底线为准，并在失效区显式写明。

**产出**：`INVALID_ZONE` 3 条；`TENSIONS` 3-4 条（每条 ≤40 字，仅标准时期注入 ≤100 字）。
**校验**：失效区条目必须是"本框架何时不该用"，不是免责声明；张力条目必须能对应原文矛盾，不得编造。

## 六、生平交叉（Life × Text）

**问题**：写作时的处境（流亡、坐牢、执政、被批判）如何影响表达？

**步骤**
1. 给每篇核心文本标写作地点与政治处境。
2. 检查时期划分是否与处境变化对齐（处境变了、文风没变，说明时期划分有问题）。
3. 聊天 persona 的时代边界（"你死于 X 年，不知道后来的事"）必须与本维一致；不得让导师谈论其身后事件（除显式设定的"回望"模式）。

**产出**：时期边界表（供 `marxist-style.js` 聊天 persona 使用）。
**校验**：聊天中问"后来的事"，回答必须体现时代边界，而不是假装知道。

## 执行顺序与工作量

1. 四、六 先做（书目 + 年表，成本低，决定后面边界是否站得住）。
2. 一、二 其次（脉络 + 论敌，需要读全量文本）。
3. 三 最后（表达 DNA，最耗时，但只有前面站稳才不会写出"像但不对"的 Prompt）。
4. 五 与三并行（失效区/张力是表达的边界条件）。

单导师预计 2-4 个工作日；本轮马克思复用上游素材落地了二、五、六的骨架。
