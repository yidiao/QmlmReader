# 议题训练库（C4）

> 2026-11-13 落地，2026-11-14 升级为抽屉选题。两份外部素材合成一个 179 条议题池，供页面选题与批量训练/评测使用。
> 只存“题目”，不预置答案，也不预置任何生成结果。

## 一、两份来源

| 来源 | 条数 | 原文件 | 字段 |
|------|------|--------|------|
| 《共产主义一百问》 | 100 | `D:/AI Pj/金星与赤旗-资料集/文字/共产主义一百问.txt` | `n` 编号、`question` 问题、`category` 所属编、`tags` 标签 |
| 兄弟项目「青马的奇妙冒险」题库 | 79 | `js/qingma/data.js` → `QUESTIONS` | `id`、`enemy` 敌人名、`faction` 六大派、`weakness` 最佳论证方式、`topic` 敌人言论 |

一百问按六编组织：基本概念 / 政治经济学与社会结构 / 组织、国家与革命路线 / 历史经验与经典争论 / 当代社会热点与意识形态批判 / 展望未来与战略问题。

青马题库的 79 题是“敌人言论”，天然带错误立场与最佳拆解方式（理性辩证 / 归谬反诘 / 阶级批判 / 感性批判），适合做**论战型**训练输入。

## 二、代码位置

- 数据：`js/marxist/topics.js` → `window.MarxistTopics`
  - `hundred`（100 条）、`qingma`（79 条）
  - `all()`：统一视图，字段 `{ source, id, title, tags, category, enemy? }`
  - `random()`：随机一条
- 页面：`html/experimental/marxist-style.html` 的「议 题」行
  - 「📚 选题库（179）」：右侧抽屉，含关键词搜索（题面/标签/分类/论敌）与来源 tab（全部 179 / 一百问 100 / 青马 79）
  - 点选任一议题：填入输入框，并在「当前议题」显示来源标签（如“一百问 · 第42问 · 组织 · 劳动 / 国家 / 路线斗争”“青马 · 蝗旱 · 古董派”）
  - 「🎲 随机一题」：按当前 tab 过滤后随机抽一条填入
- 训练集：`_tools/train_topics.cjs` → `doc/pages/experimental/research/马列体/议题训练集.jsonl`

## 三、训练集怎么用

```bash
node _tools/train_topics.cjs          # 179 条课程表（元数据 + prompt 指纹，约 68 KB）
node _tools/train_topics.cjs --full   # 额外写入完整 systemPrompt
```

每条记录：

```json
{"id":"hundred-1","source":"hundred","title":"…","tags":["哲学","政治经济学"],
 "author":"stalin","period":"standard","tone":"auto","inputType":"abstract",
 "promptVersion":"prompts-gen-v1.0/guards-v1.0/stalin/standard/auto",
 "promptChars":3237,"promptSha256":"58ea57d394e1e630"}
```

编排规则：议题按顺序轮转分配 导师（5 人）/ 时期（4 档）/ 语气（8 档）；一百问按 `abstract` 输入，青马题库按 `opinion` 输入。这样 179 条能覆盖全部导师 × 时期 × 语气组合，且同一组合下不同议题可横向比较。

推荐的闭环（需要 Key，属人工执行）：

1. 取一条记录 → 用同版本装配器生成 systemPrompt → 调 `api/translate.js` 或 DeepSeek 直连生成；
2. 结果交给 `window.ArticleDB.compareStyle(output, author)` 做风格差距分析；
3. 分析写回 `logGeneration` 蒸馏日志，作为下一次生成的 `feedbackContext`；
4. 人工抽检：经典引用是否原文可查、论敌是否打对、语气是否与所选档一致。

## 四、边界

- 不预置“标准答案”：一百问原文本身是写作规范与问题清单，青马题库的 `options` 只在游戏内使用，训练库只取题干。
- 不做政治内容过滤：题目照原样保留，包括革命暴力、国家机器、民族叙事等敏感议题；这是严肃训练素材，不是玩具。
- 议题库与 `article-db.js` 的 `opponents` 是两层：议题是“练什么题”，论敌是“这篇文章在跟谁打”。
