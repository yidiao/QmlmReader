## 0. 定位与母站关系

**一句话**：可当小说读的剧本 + 喂给 AI 生图/音乐/视频的 prompt 包。用户挑一个当代矛盾（劳动 vs 资本、环保 vs 逐利……），套老样板戏的骨架和精神内核，AI 逐幕写出「新时代样板戏」，最后导成下游生产用的提示词。

**在闭环中的角色**：传播 / 创作——从「读」走向「演」，把抽象的社会矛盾唱成戏。

**视觉关系**：**独立 · 革命时期农村风格**（接地气的乡土戏台）——既不是母站红金黑深化，也不是现代化跳脱，是自成一派的革命农村写实美学。

> ⚠️ 方向变更记录：`武器库-总览.md` V1.1 原定为「舞台幕布 × 霓虹分镜（跳脱·现代化）」。落地后改为乡土戏台，视觉归为**独立的革命时期农村风格**，不是红金黑设计语言。理由见 §3。

**「赛博」二字的正解**【新增】：赛博 ≠ 霓虹视觉，而是指 **AI 生成这个赛博能力**——老戏台唱新戏、AI 当编剧。形式（戏台）与内容（样板戏）统一，「赛博」体现在生产方式（AI 直连生成），形成「乡土形式 × 赛博生产」的反差。

## 1. 现状整合（v3 原型，已实现）

> 状态：🔧 原型（`html/experimental/`），非概念期。以下均已落地，本节是「更新」相对总览 V1.1 的最大差异——总览把它当概念，实际已有可跑的原型。

### 1.1 三阶段生成流程

| 阶段 | 用户动作 | 系统处理 |
|------|---------|---------|
| 一 · 定框架 | 挑矛盾类型、剧种、幕数、填角色名、写核心唱段主题、贴 API Key | 渲染选择器 + 角色卡 |
| 二 · 逐幕协作 | 点「AI 写这幕」逐幕生成，改到满意；或「AI 一键写全部」 | 幕弧线生成 + agent 发任务（带全局梗概 + 前文进度 + 第 N 场 + 核心唱段唯一） |
| 三 · 提示词 | 切「分镜脚本 / Prompt 包」tab，导出 | 逐幕渲染分镜卡 + prompt 卡 |

### 1.2 文体 Prompt（蒸馏自八大样板戏）

已沉淀成 `js/yangbanxi/yangbanxi-prompt.js` 的 System Prompt，包含：
- **角色定义**：三突出（英雄居中、高大全、亮相）+ 敌我分明 + 核心唱段是情感政治顶点 + 胜利升华。
- **板式体系**：西皮散板/原板/流水/摇板/垛板，各对应情绪节奏（京剧标板式；芭蕾写舞蹈段落；交响乐写乐章）。
- **唱词风格规则**：口语化、三突出、敌我分明、革命意象、对仗押韵、唱词带情境。
- **结构框架**：亮相 → 周旋 → 危机 → 核心唱段 → 胜利，幕数 6–10+，核心唱段全剧唯一。
- **禁止事项**：禁泛泛口号、禁丢板式、禁脱离题材、禁抹杀英雄、禁给敌人人性光辉、禁文言堆砌。
- **Few-shot 示例**：红灯记/智取威虎山/沙家浜 六段经典唱段。
- **agent 发任务模式**：每次调用带「全局梗概 + 前文进度 + 当前场次」三层上下文，硬性约束场次编号连续、核心唱段唯一、不重复前文。

完整 Prompt 见 `样板戏研究-文体Prompt.md`（研究稿）与 `js/yangbanxi/yangbanxi-prompt.js`（落地代码）。

### 1.3 已支持的可变维度

| 维度 | 选项 |
|------|------|
| 矛盾类型（6 种，新时代内容入口） | 劳动 vs 资本 / 群众 vs 官僚 / 诚信 vs 造假 / 进步 vs 守旧 / 环保 vs 逐利 / 个体 vs 困境 |
| 剧种（3 种） | 京剧 / 芭蕾舞剧 / 交响乐 |
| 幕数 | 6–10（滑块） |
| 角色 | 主角（英雄）/ 敌人 / 群众，各带类型 + 默认名 |

### 1.4 文件清单

| 文件 | 状态 |
|------|------|
| `html/experimental/yangbanxi.html` | 工具页面（三阶段 + 横额/灯笼/帷幕/舞台） |

## 2. 更新需求

> 三路来源合并：`武器库-我的更新大纲.md` 赛博样板戏段 + `武器库-总览.md` 2.4 拓展 + 现状缺口（读代码发现）。逐条取舍。

### 2.1 原文已提出【已有】

1. **剧本 × prompt 双产出**：既是「可当小说读的剧本」，也是「AI 生图/音乐/视频的 prompt」。✅ 已部分实现（分镜脚本 + Prompt 包两视图），但**只做了生图 prompt，音乐/视频 prompt 未做**。
2. **发掘老样板戏**：汲取经验、搭骨架、留精神内核。✅ 已做（八部研究笔记 + 文体 Prompt 蒸馏）。
3. **用户自己填新时代内容**：✅ 已做（6 种当代矛盾类型）。
4. **AI 辅助生成下游 prompt**：✅ 已做（阶段三 Prompt 包 + 导出）。

### 2.2 拓展补充【新增】

（来源：总览 2.4 + 读代码发现的现状缺口）

1. **分镜脚本生成器升级**：现在分镜是硬编码 `['全景','中景','特写']` 轮换，不是 AI 按剧情生成。应改为——AI 为每幕输出「画面描述 / 台词 / 景别 / 时长」，再据此生成生图/视频 prompt。
2. **补「音乐 / 视频」prompt**：更新大纲明确要「生图、音乐、视频的 prompt」。当前只生成生图 prompt（`style` 字段）。应加配乐 prompt（京剧板式 → 配器/节奏描述）与视频 prompt（分镜 → 运镜/时长）。
3. **核心唱段「命名」环节**：研究强调「核心唱段要带名字」（打虎上山/智斗/北风吹）。现在只有一个「核心唱段主题」输入框，未生成具体的唱段名。应在阶段二给核心唱段场加「命名」步骤。
4. **样板戏骨架库**：现在幕弧线是硬编码 `亮相→[中间 N 幕]→核心唱段→胜利`。应把老样板戏的叙事骨架提炼成可复用模板库（如「卧底智取型」（智取威虎山/奇袭白虎团）、「茶馆智斗型」（沙家浜）、「成长复仇型」（白毛女/红色娘子军）、「建设暗斗型」（海港）），用户选题材后匹配对应骨架。
5. **角色类型库补「旁观者」**：总览提「英雄/反派/群众/旁观者」四类。现在只有主角/敌人/群众三类，缺「旁观者」。
6. **三种产出形态独立视图**：总览要求「小说式阅读 / 分镜脚本 / prompt 包」三视图自由切换。现在「小说式阅读」是阶段二的剧本编辑态，阶段三只有分镜/prompt 两 tab，缺一个「通读全文」的沉浸式小说视图。
7. **剧种差异化渲染**：Prompt 已区分京剧/芭蕾/交响乐，但渲染层 `renderShots`/`renderPrompts` 未区分——芭蕾应出「舞蹈段落」，交响乐应出「乐章」，而不是统一当「唱段 + 台词」处理。
8. **骨架复用与历史记录**：localStorage 存「已生成的戏」，支持回看、导出、二次编辑（对齐马列体的「蒸馏日志」思路）。

## 3. 视觉交互设计（乡土戏台 · 独立革命农村风）

### 3.1 设计切入

> 为什么放弃霓虹、回到乡土戏台【新增】：
> - 老样板戏本来就是「戏台」——横额、红灯笼、红布幕、木台，这些元素本身就有强烈的舞台仪式感，比硬贴霓虹更贴「样板戏」的本体。
> - 「赛博」落在 **AI 生成** 这个生产方式上，不必靠霓虹视觉硬撑。乡土形式 × 赛博生产，反差本身就是记忆点。
> - 它是武器库里**唯一走「革命时期农村写实」皮肤**的工具：不是马列体那种构成主义红金黑，也不是青马的终端绿、万物的暗房灰，而是自成一派的农村戏台质感。

### 3.2 色板（革命时期农村戏台的写实配色）

| 角色 | 色值 |
|------|------|
| 大红横幅（主红 = 母站 `#c41e3a`） | `#c41e3a` |
| 红布帷幕 | `#a01828`（暗色 `#7a0c1e`） |
| 追光金（= 母站 `#ffd700`） | `#ffd700` |
| 木纹舞台 | `#8b5a2b` / 深木 `#5f3d1e` |
| 舞台米纸（底） | `#f5e8d0`（暗色 `#242019`） |
| 朱红强调 | `#d4380d` |
| 土绿点缀 | `#4a6741` |
| 墨黑 | `#1a1a1a` |

### 3.3 落地要点（已落地，`css/yangbanxi-style.css` 为准）

- **横额**：大红横幅 + 金色五角星（`::before/::after`）+ 宋体大字标题（`letter-spacing: 8px` 拉开），大字报感。
- **红灯笼**：`repeating-linear-gradient` 竖条纹 + 金色提梁，纯 CSS 绘制。
- **红布帷幕**：`repeating-linear-gradient` 褶皱 + 金色下摆 `border-bottom`。
- **两侧垂幕**：竖向褶皱 + 底部流苏（`radial-gradient` 圆点 repeat-x）。
- **木纹舞台框**：`8px` 木色 border + 双层 `inset` 木纹描边 + 硬阴影，像搭起来的戏台。
- **硬阴影、直角、归零圆角**：按钮/卡片统一 `box-shadow: 4px 4px 0`、`border-radius: 0`，与马列体同源。
- **动效克制**：按钮 hover 位移 2px、flash 提示浮层 0.4s，150–200ms 节奏。
- **仍继承母站骨架**：导航、暗色模式 `body.dark-mode`（天然适配，CSS 变量整套切换）、自定义光标照常挂载。

### 3.4 待补的视觉【新增】

- 阶段三「Prompt 包」目前是白底 `pre`，可做成「剧本场记板」样式（黑底白字 + 场次打板条）。
- 「通读全文」小说视图（若做 2.2-6）可加**聚光灯跟随当前分镜**（`radial-gradient` 锥形光斑），呼应总览原「舞台追光」的设想。

## 4. 全流程

```
进入 → 阶段一 定框架
        ├ 矛盾类型(6) ── 决定敌人/主角/时代背景
        ├ 剧种(3) ── 京剧(板式) / 芭蕾(舞蹈段落) / 交响乐(乐章)
        ├ 幕数(6-10)
        ├ 角色(主角/敌人/群众) + 核心唱段主题
        └ API Key(DeepSeek，与马列体同 key 体系，LS 独立)
          ↓
       阶段二 逐幕协作
        ├ 生成幕弧线(亮相→…→核心唱段→胜利)
        ├ 每幕「AI 写这幕」/「AI 一键写全部」
        └ agent 发任务：全局梗概 + 前文进度 + 第N场 + 核心唱段唯一
          ↓
       阶段三 提示词
        ├ 分镜脚本 / Prompt 包 两 tab 切换
        └ 导出 prompt 包 → 喂 AI 生图/音乐/视频
```

| 步骤 | 用户动作 | 系统处理 | 界面呈现 |
|------|---------|---------|---------|
| 1 定框架 | 点矛盾类型 → 选剧种 → 拉幕数 → 填角色/唱段主题 | 载入题材预设 + 角色默认名 | 选择器卡片 + 角色卡 |
| 2 逐幕写 | 点「AI 写这幕」 | agent 带上下文调 DeepSeek | 幕卡片（场次 + 描述 + textarea 可改） |
| 3 出提示词 | 切 tab / 点导出 | 逐幕渲染分镜 + prompt | 分镜卡 / prompt 卡 |
| 4 导出 | 点「导出 Prompt 包」 | 打包 .txt | 下载 |
