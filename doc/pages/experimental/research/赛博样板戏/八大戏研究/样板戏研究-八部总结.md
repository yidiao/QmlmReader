## 二、共性原则（八部共享的「核心」，不可丢）

1. **三突出**：英雄居中、仰角、红光；「高大全」无缺点；关键处「亮相」定格。
2. **敌我矛盾**：永远是阶级/民族矛盾，敌人脸谱化（日寇/土匪/地主/暗藏敌人/美伪）。
3. **核心唱段/乐段**：全戏必有情感 + 政治的双重顶点（红灯记「都有一颗红亮的心」、智取威虎山「打虎上山」、沙家浜「智斗」、白毛女「北风吹」）。
4. **胜利结局 + 升华**：英雄必胜，主题上升为「革命/解放/为人民」。
5. **时代背景明确**：每部都锁定一个具体历史阶段。

## 三、差异维度（生成器必须可变的，我上一版全漏了）

1. **题材（至少 6 种）**：抗日 / 剿匪 / 社会主义建设 / 抗美援朝 / 土地革命 / 阶级斗争
2. **剧种（3 种）**：京剧（有唱段板式）/ 芭蕾舞剧（无唱，靠舞蹈音乐）/ 交响乐（纯音乐）
3. **主角身份**：工人 / 侦察军人 / 地下党员 / 党支书 / 贫农女儿……
4. **敌人类型**：日寇 / 土匪 / 地主 / 暗藏敌人 / 美伪军 / 汉奸……
5. **结构**：场次数量、场名都不同（6–11 场），不是固定「五场」

## 四、对生成器的改版启示

1. **先选题材**——题材决定敌人、主角身份、时代背景（这是「新时代内容」的入口）。
2. **再选剧种**——京剧走唱段板式；芭蕾走舞蹈 + 乐段；交响乐走纯音乐。
3. **然后套「三突出」骨架**——无论题材怎么变，都有一条不变的弧线：
   `矛盾登场（亮相）→ 与敌周旋 → 受难/危机 → 核心唱段（情感政治顶点）→ 胜利升华`
   注意：这不是「起承转合」，而是「三突出」原则下的敌我斗争弧线，但**场次数量、场名、敌人、主角都要随题材变**。
4. **核心唱段是灵魂**——每一部都必须有一个带名字的核心唱段（像「打虎上山」「智斗」），这是全戏的记忆点，不能是泛泛的口号。

## 五、结论

样板戏 = **「三突出」的固定原则 ＋ 完全开放的题材/剧种/敌人/主角组合**。
上一版生成器的错，是把《红灯记》的「抗日 + 接头 + 叛变」误当成了通用骨架。改版应该反过来：**原则固定，素材（题材/剧种/敌人/主角）开放**。
