# QmlmReader 经验笔记（学习层）

> **性质**：产品层与工程层之间的学习层。人机双读：人类按笔记读，AI 按条目检索。
> **写法**：每条 = 场景 → 坑 → 解法，不超过五行。工程中的教训随时登记（这是工程层→学习层的流向规则）；从成熟代码/网上学来的 UI 技巧与最优路径也记这里。
> **纪律**：只写可复用的结论，不写流水账；与某文件强绑定的规范放 design-tokens.md / 模块 README，这里放"为什么"和"怎么防"。

## 一、工程坑

### 1. 行内样式转类的五类副作用（2026-11-07，C6 实战）
- **场景**：把 661 处 `style=""` 转成类。
- **坑**：① 行内"必胜"语义丢失，被 `.tab-content p` 这类 (0,1,1) 规则反杀；② `[style*="object-fit"]` 属性选择器随行内属性消失而失配（toolkit.css .hero-avatar）；③ JS 运行时注入的行内样式不在静态源里，别碰；④ `onmouseover="this.style.background=…"` 之类处理器引用行内样式，转类时不能动；⑤ 元素跌回 UA 默认色（蓝链）是"完全没命中规则"的信号，不是特异性输赢问题。
- **解法**：双类选择器（见最优路径 2）+ 属性选择器规则补新类 + 只转静态源 + 转完用单点计算值/截图验证。

### 2. python http.server 没有 Cache-Control（2026-11-07）
- **场景**：本地 8642 端口测试页面改动。
- **坑**：Chromium 按启发式（资源龄 10%）缓存，旧文件可能数小时不重验证——页面引用的 css/js 停在几个版本前，制造大量"假回归/假矛盾"，且 `?v=` 只能骗过 HTML 引用层，子资源仍吃缓存。
- **解法**：自建带 `Cache-Control: no-store` 的服务器最干净；临时可用「克隆 `<link>` 换带时间戳查询串 + 等 load 事件」绕过；验证磁盘真身用页内 `fetch(url, {cache:'no-store'})`。

### 3. 批量 getComputedStyle 会踩样式重算竞态（2026-11-07）
- **坑**：换样式表后立刻遍历全元素读 computed，部分元素读到旧值，与单点读取、截图互相矛盾，排查数小时。
- **解法**：以截图为地面真值；单点读取可信；批量快照必须等 load 事件 + 余量延时，且读前强制 `void el.offsetWidth`。

### 4. 生成器投影裁剪字段会让消费者长出兜底（2026-11-07，A6）
- **坑**：`build_data.py` 把 articleIndex 裁成 8 字段投影，articles.html 被迫内嵌 29 条全字段兜底 JSON + 多级 fallback 链，越积越大。
- **解法**：生成器整条复制；发现页面有内嵌兜底数据时，先查"是不是生成器少给了字段"，别急着收敛页面。

### 5. 跨文件类型语义耦合（2026-11-07，A6）
- **坑**：search.js 存在 `priority === '5'` 严格比较；改生成器把 priority 转成 number 会静默破坏搜索。
- **解法**：改共享数据结构前 grep 消费方的比较写法；类型语义写进生成器注释。

### 6. 目录改名后旧路径引用会长期潜伏（2026-11-06）
- **坑**：`设计文档/` 改名 `doc/` 后，7 个文档残留 23 处旧引用，README 之间互相指向不存在的路径。
- **解法**：目录/文件改名 = 全库 `grep 旧名 --include=*.md` 清零后才算完成；归档长文可豁免但要登记。

### 7. Git Bash 的 sed 会剥 CRLF（2026-11-07）
- **坑**：`sed -i` 处理 Windows 换行的 HTML 后整文件变 LF，diff 全行污染。
- **解法**：批量文本手术用 python（`io.open(newline='')` 读写），或事后 `unix2dos`；CSS 保持 LF、HTML 保持 CRLF 是本库现状。

## 二、最优路径

### 8. 双类选择器：不加 !important 的特异性提升（2026-11-07）
- 行内样式转类/通用规则要压过组件规则时，把选择器写成 `.x.x`（0,2,0），同文件内靠加载顺序赢平局。比 !important 干净，可全局机械化执行。

### 9. 计数断言脚本防文档漂移（2026-11-07，A3）
- 文档里的"30 篇/34 个 JSON"类数字必然漂移。写 `_tools/check_docs.py`（只读、stdlib、`-I` 运行）输出全部计数断言，文档标"以脚本 YYYY-MM-DD 实测为准"。本轮 4 处数字失实全因此根治。

### 10. 文档三层结构 + 流向规则（2026-11-07）
- 产品层（README 索引 / PLAN 干净表单 / preparing 筹备档）、工程层（模块维护指南）、学习层（本文件）。纪律：教训→学习层；跨模块任务→PLAN；模块私事→模块 README。三者互相只放指针，不抄内容。

### 11. 无框架状态中心的渐进迁移（2026-11-07，源自 architecture §5 案例）
- 路径：先立 store（五域 preferences/theme/reader/search/ui）→ 双写兼容旧 localStorage 键 → 页面私有状态走 `QMLMPageState.patch('pageXxx')` 适配层 → 逐页收拢。原则：单一写入口、先状态后 DOM、派生状态不落库、UI 白名单持久化（`UI_PERSIST_KEYS`）。
- 详史在 architecture/README.md §5（已压缩为现状参考）。

### 12. 子代理按"文件所有权"分治（2026-11-07）
- 并行子代理各占互不重叠的文件集（如 A 管 style.css、B 管 articles 两 css），交叉文件由主控先裁定所有权（谁改某页谁连带做该页全部改动）；并发上限约 4，超限任务会报 user concurrency limit exceeded，补发重跑即可。

### 13. 数据/页面手术前先做"逐字节基线"（2026-11-07）
- 大规模样式/内容迁移前，抓基线快照（如每页 [style] 元素的结构路径 + 计算样式指纹），改完同路径对比。语义等值改动用"git show HEAD 逐字回写比对"验证。两板斧让 661 处转换做到零视觉回归。

## 三、UI 技巧

### 14. 护眼纸四档体系（color-system §2）
- 页面底 `--paper-page #f3eadc` → 区块 `#f7f2e7` → 卡片 `#fffaf0` → 浮层 `#fffdf7`，边框 `#ded2bd`。层级感靠四档纸面而不是阴影堆叠；纯白只给图片容器。

### 15. 深底浅字 hero 与模块强调色的压制关系（2026-11-07，B5）
- 门户 hero 若是深底浅字设计（gallery/experimental/rectify/downloads），模块强调色只能作用于暗色模式或徽标，**不要盲改文字色**；浅底 hero 才吃得下 accent。激活模块色前先看 hero 背景。

### 16. z-index 阶梯 + 特例冻结（design-tokens §5）
- 阶梯：内容 0-10 / 置顶 100 / 导航 900-999 / 遮罩 1000-1099 / 弹窗 1100-1299 / 特效 9500-9999 / 特例 10000-11999（光标 10000、进度条 12000 冻结）。新代码从 `--z-*` 取值，禁止散值。

### 17. 品牌红的柔化变体族（2026-11-07，B9）
- 主红 #c41e3a 之外，柔化场景用 `--color-brand-red-soft #ff6b6b`、`-soft-dark #e57373`、`-strong #b91c1c`；暗色大面积红永远用柔化红，纯红只给小面积强调。

### 18. experimental 工具族独立视觉 + 母站骨架（design-tokens §12）
- 子工具可自带令牌体系（--ms-/--qm-/--yb-…）与硬阴影、无圆角，但导航、暗色接入、相对路径三件事必须接母站。

### 19. 马列体美术设计（占位，待 A7 细拆）
- 来源：research/马列体/马列体生成器-美术设计.md。细拆后本条替换为提炼出的通用技巧。

### 20. 构成主义 UI 的灰阶纪律（color-system §8）
- 同一灰值不同时承担正文/边框/背景；用 `--gray-950…050` 十二档，暗色另有 `--gray-dark-*` 九档。灰阶混乱是"有的地方偏黑有的边框发白"的根源。

## 四、黑夜模式与浏览器验证（2026-11-07）

### 21. 黑夜模式首帧预渲染（反 FOUC 三件套）
- **场景**：暗色用户跳转页面先闪一帧白日样式。
- **坑**：主题类靠 `</body>` 前的外部 darkmode.js 挂 `<body>`，首帧渲染早于脚本执行；**今后新生成页面若漏带 head 内联脚本，白闪即复发**。
- **解法**：head 内联脚本（`qmlm:dark-mode-prerender` 标记注释，幂等可复跑 `_tools/add_dark_mode_head_script.py`）置于所有样式表之前给 `<html>` 挂类 + CSS 全量 `body.dark-mode`→`.dark-mode body`（特异性不变，765 处）+ darkmode.js 双类同步。importer 模板与 soviet-jokes 页（独立 `sj-archive-theme` key）均已补丁。

### 22. 浏览器自动化验证的三个伪象
- **坑**：① IAB/无头环境合成器节流，全页 `CSSTransition` 冻结在 `currentTime=0`，"点击切换后颜色不变"是假象，`getAnimations()` 一眼识破；② 页面 `pagehide`/`beforeunload` 挂持久化钩子（preferences.js:1174），测试中 `localStorage.clear()` 后 reload 会被内存态回写，制造"清不掉"；③ state-center 的 `qmlm:state:v1` 优先级高于 legacy `darkMode` 键，手改 legacy 制造分歧必被覆盖。
- **解法**：模拟"首帧时外链脚本未执行"用资源改名 404 法（darkmode.js→.bak 后 goto，看首帧状态）；状态变更一律走页面真实按钮路径；对照基线用 `git worktree` + 独立端口起服务（跨端口=跨 origin，localStorage 隔离，两边都要各自设偏好）。
