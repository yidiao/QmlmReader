关于本展

展览说明 / ABOUT

这是一张关于资本主义与社会主义的历史演化总图。主画布只保留 55 个主干节点，用时间带与领域泳道确定位置；人物、著作、组织与更细的争论收纳进完整档案目录。

主画布是展览主体，档案目录是检索仓库；两者可以互相跳转，但叙事只发生在主画布上。

每个词条分为概览、深读、关系、来源与策展说明五页；深读按「理论、实践、历史、贡献、批评、后世影响」六段展开，先覆盖全部主干词条，再分批扩展到档案层。

关系语义 / EDGE SEMANTICS

实线
有来源支撑的事实关系（如发展自、变体、制度化、竞争等）
虚线
策展父边：为稳定阅读结构而保留，表示「在此叙述」，不表示唯一历史因果
颜色
蓝＝思想影响，棕＝制度化，红＝竞争/冲突，绿＝主干演化
菱形 / 六边形
重大转折事件 / 组织节点，附属于主干但不打断主线
缩放层级
远景（<60%）只留标题看结构，中景（60%—120%）读摘要与出处，近景（>120%）展开英文名、三行摘要与一行元信息

数据与来源 / DATA & SOURCES

来源分为原始文献、学术研究与公共资料三类；未实际核验的链接不会登记。关系证据逐步补齐，仍有部分关系标注为「有争议」或「待审校」，它们不代表价值判断。

学术讨论定位 / ACADEMIC FRAMING

本展是历史社会学与政治经济学的学术讨论材料，用于教学、研究与公共讨论，不是政治宣传，也不代表任何政党、政府或组织的立场。

对革命、镇压、战争、饥荒与制度竞争等争议议题，页面并列不同史料与解释传统，并标注「已确认 / 较可信 / 有争议 / 推测」等证据状态；深读文本中的判断均为可追溯的学术综述，不是定论。读者应把它当作研究提纲，而不是立场声明。
