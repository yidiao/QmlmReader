# 样板戏研究笔记 · 京剧《红灯记》

> 忠于史实第一步（八大样板戏之一）。本文为分析综合，唱段仅节选少量原文供研究。

## 基本信息
- 剧种：革命现代京剧
- 时代：抗日战争时期初冬，北方「隆滩火车站」附近
- 主线：李玉和一家（非血缘三代）保护、传递密电码，抗日斗争

| 人物 | 身份 | 功能 |

## 核心唱段（节选，含板式标注）
- 李玉和【西皮原板】「提篮小卖拾煤渣，担水劈柴也靠她……穷人的孩子早当家」

## 唱腔板式（工具必须体现，我原模板完全遗漏）
| 板式 | 节奏 | 用途 |
|------|------|------|
| 西皮散板 | 自由 | 叙事 / 铺垫 |
| 西皮原板 | 2/4 中速 | 抒情 / 交代 |
| 西皮流水 | 1/4 快板 | 情绪急促 |
| 西皮摇板 | 紧打慢唱 | 紧张 |
| 西皮垛板 | 字字铿锵 | 高潮 / 表决心 |

配器：京剧唱腔 + 西洋交响乐（中西合璧）。

## 三突出的具体体现
1. 李玉和始终居中、正面、红光——「一号英雄」
2. 反面人物（鸠山 / 王连举）脸谱化、鬼化
3. 核心唱段 = 政治主题 + 情感的双重顶点

## 学术评价要点（二分法）
- **成就**：京剧音乐继承与革新、现代题材开拓、表演程式革新、唱词口语化个性化
- **局限**：三突出被绝对化 → 公式化、脸谱化；反面鬼化；人性抹杀；沦为政治工具
- 关键判断：「问题不在戏内，而在『样板』的政治定位本身」
