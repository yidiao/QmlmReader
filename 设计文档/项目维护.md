# QmlmReader 项目维护入口

> 兼容入口：历史上 AI 和人工常先读本文件。现在真正的总入口已调整为 `设计文档/README.md`。  
> 如果只读一份文档，请读：`设计文档/README.md`。

---

## 1. 当前文档体系

```text
设计文档/README.md                  # 总入口：给我看 + 给 AI 看
设计文档/architecture/README.md     # 全站架构、公共脚本、公共样式
设计文档/data/README.md             # 数据层、正文层、精读层、下载导出
设计文档/pages/README.md            # 页面模块索引
设计文档/pages/<module>/README.md   # 每个 html 模块一个 README
```

---

## 2. 当前任务状态

“正文层、精读层、渲染层解耦”在本阶段视为**规范完成**。

已经形成的约定：

- 正文层：`data/articles-json/{Mentor}/{Star}/{slug}.json`
- 精读层：`data/study-json/{Mentor}/{slug}.json`
- 渲染层：`js/article-json.js`、`js/article-study.js`、`js/article-common.js`
- 页面层：`html/articles/{Mentor}/{slug}.html` 作为精读页壳

后续如果继续推进，应另开任务处理具体页面迁移，不再把它当作“最近未完成任务”。

---

## 3. AI 快速执行口径

1. 先读 `设计文档/README.md`。
2. 页面任务读 `设计文档/pages/<module>/README.md`。
3. 数据任务读 `设计文档/data/README.md`。
4. 公共架构任务读 `设计文档/architecture/README.md`。
5. 再读真实代码，不要只凭文档修改。
6. 修改后同步更新对应 README。

---

## 4. 误判规避说明

本项目包含若干历史、文艺、实验工具相关资料。为了降低自动安全过滤误判：

- 总入口只使用工程化模块名。
- 长篇研究稿和 Prompt 资料放在 `设计文档/pages/experimental/research/`。
- AI 做维护时优先读取路径、接口、脚本、样式、数据结构；非必要不展开正文和描述性文本。
