## 1. 母站统一框架

**共享骨架（所有工具继承母站，保证是一家人）**
- 全局导航栏（红色渐变 sticky + 金下划线激活态）——工具页面挂进 `toolkit/` 或 `experimental/` 后共用一份导航。
- 暗色模式 `body.dark-mode` toggle（🌙）+ `localStorage` 记忆。
- 自定义光标（镰刀锤头 / 红五星，移动端禁用）。
- 母站红金黑 `#c41e3a / #8b0000 / #ffd700` 作为**基础锚点**。
- 字体尺度（无衬线正文 + 宋体标题）、动效节奏（过渡 150–200ms）。

**独立皮肤（每个工具版式/纹理/几何/交互各做特色）**
- 版式、纹理、几何语言、交互节奏各自独立，见第 3 章。

**跳脱空间**
- 部分工具可**彻底脱离红金黑，走向现代化设计**（如终端绿 BBS、暗房灰调）。跳脱的工具仍保留共享骨架（导航/暗色/光标），只在**皮肤层**走自己的配色与版式。（注：赛博样板戏原列为跳脱·霓虹，落地后归为**独立·革命农村风**——既非红金黑深化，也非现代化跳脱，见 2.4/3.4。）

## 3. 视觉交互设计（落地）

> 设计总纲：**共享骨架 + 独立皮肤 + 允许跳脱。**
> 共享骨架 = 母站导航 / 暗色模式 / 自定义光标 / 红金黑锚点 / 字体尺度 / 动效节奏。
> 独立皮肤 = 每工具在版式 / 纹理 / 几何 / 交互语言上各做特色。
> 跳脱 = 部分工具彻底离开红金黑、走现代化配色，但仍保留共享骨架。
> 质量基准：马列体生成器（`css/marxist-style.css`）确立的标准——**先弄懂引用什么美学传统再写 CSS；颜色承担结构角色；硬阴影、锐利几何、归零圆角**。

### 3.1 马列体生成器 —— 构成主义 × 革命美术【继承红金黑】

> 详述（色板/核心手法）见 `设计文档\马列体\马列体生成器-美术设计.md`。它是**其他工具复用的质量标尺**：先弄懂引用什么美学传统再写 CSS；颜色承担结构角色；硬阴影、锐利几何、归零圆角。

### 3.2 青马的奇妙冒险 —— 「论坛 / 聊天室对战风」【跳脱·现代化】

**设计切入**：敌人本就是「在互联网发表错误言论」的人，界面做成老式论坛/BBS + 聊天软件混合体，走向早期互联网终端美学。详述（色板/落地要点）见 `设计文档\青马\青马的奇妙冒险设计大纲.md` §4。

### 3.3 小册子 —— 「黑板报 / 手抄报红刊风」【继承红金黑】

**设计切入**：小册子是「手工红刊」，印刷感 + 手作感，像一本自己抄写绘制的刊物，天然落在红金黑体系内。详述（色板/落地要点）见 `设计文档\小册子\小册子-设计文档.md` §2。

### 3.4 赛博样板戏 —— 「革命文化 × 乡土戏台」【独立·革命农村风】

> ⚠️ 方向已从 V1.1 的「霓虹分镜（跳脱）」改为「乡土戏台（独立革命农村风）」，理由见独立文档 §3.1。详述（色板/落地要点）见 `设计文档\赛博样板戏\赛博样板戏-设计文档.md` §3。

**设计切入**：老样板戏本就是「戏台」——横额、红灯笼、红布幕、木台自带舞台仪式感；「赛博」落在 **AI 生成** 这个生产方式上，不必靠霓虹视觉硬撑，乡土形式 × 赛博生产，反差即记忆点。是武器库里**唯一走革命时期农村写实皮肤**的工具。

**落地已做**：横额大红横幅 + 金五角星 + 宋体大字标题、红灯笼、红布帷幕、两侧垂幕、木纹舞台框、硬阴影直角。

### 3.5 万物皆可红 —— 「暗房冲印红调风」【跳脱·现代化】

**设计切入**：照片处理 → 老式暗房/冲印工作台，暗房安全灯本身就是红色，天然呼应「红化」主题。详述（色板/落地要点）见 `设计文档\万物皆可红\万物皆可红-设计文档.md` §2。

## 6. 全流程设计（端到端）

> 把每个工具「从打开到拿到结果」的完整链路写清楚，作为落地开发的施工图。

### 6.1 马列体生成器（已落地）

> 全流程施工图见 `设计文档\马列体\马列体生成器-大纲架构.md`。

选导师 → 选时期 → 输入(≤6页) → 分类器 → 片段匹配 → DeepSeek → 输出(诊断/溯源/明细) → 分享/问答。

### 6.2 青马的奇妙冒险（已落地 + 扩展）

> 全流程见 `设计文档\青马\青马的奇妙冒险设计大纲.md` §5。

标题屏 → 战斗(50题) → 结算 → 再来一局；单回合：抽题 → 敌人发难 → 4-5 选项 → 判定 → 三属性变化 → 连环击/下一题。扩展：商店、图鉴、立绘、战绩卡、存档。

### 6.3 小册子（全流程）

> 全流程见 `设计文档\小册子\小册子-设计文档.md` §3。

选模板 → 填内容(手动/创作公式 AI) → 实时预览 → 导出 PDF(@media print) → 扫码分享。

### 6.4 赛博样板戏（全流程）

> 已落地为三阶段，详见独立文档 §4：

```
阶段一 定框架（矛盾类型/剧种/幕数/角色/核心唱段主题/API Key）
  → 阶段二 逐幕协作（AI 逐幕写唱词，agent 带三层上下文，用户可改）
  → 阶段三 提示词（分镜脚本 / Prompt 包 两 tab，导出）
  → 喂 AI 生图/音乐/视频
```

### 6.5 万物皆可红（全流程）
