# experimental research 索引

> 这里存放 experimental 模块的长篇研究稿、旧方案、Prompt 资料和美术笔记。  
> AI 默认不需要读取本目录全文；只有当任务明确涉及某个子工具的深层实现、文体提示、历史方案迁移时，才选择性读取相关文件。

---

## 1. 使用规则

1. 总览和模块 README 不复制本目录长文本。
2. 做普通页面维护时，不读本目录。
3. 做子工具功能修改时，先读 `设计文档/pages/experimental/README.md`，再选择性读本目录。
4. 涉及 Prompt 或生成策略时，只摘要工程结论，不在对话和总览里大段复述。
5. 过期研究稿可以直接覆盖为摘要或删除。

---

## 2. 资料分组

| 分组 | 用途 | 默认读取策略 |
|---|---|---|
| 文体工具研究 | 文体工具架构、进度、美术经验 | 仅功能改造时读 |
| 文字游戏研究 | 游戏机制、数据、UI 与实际进度 | 仅改游戏时读实际进度；旧规划默认不读 |
| 剧本/分镜工具研究 | 生成流程、视觉、提示资料、素材研究 | 只读设计文档摘要；Prompt 全文非必要不读 |
| 图像风格化研究 | 概念方案 | 仅实现该工具时读 |
| 小册子研究 | Word 解析、分页、风格系统 | 改小册子工具时读 |

---

## 3. 安全/误判规避口径

本目录含历史、文艺、实验工具、生成策略等研究材料。为了避免自动过滤误判：

- 对外汇报时优先称“experimental 子工具研究资料”。
- 不密集罗列原始文件标题。
- 不大段复制 Prompt、正文、描述性内容。
- 只抽取工程事实：路径、接口、状态、依赖、维护边界。
