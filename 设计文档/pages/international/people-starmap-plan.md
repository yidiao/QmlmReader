# 国际共运人物大星图计划

> 对应未来源码：`html/international/people-starmap.html`、`html/puzzle/puzzle.html` 的人物图层、`html/masters/*/relations.html` 的导师局部星图。  
> 当前状态：已完成斯大林局部恒星系 Canvas 测试版与第一轮“星系语法重构”；下一步应把验证过的天体分类、轨道语法与档案结构迁回 Qmlmreader 正式页面。  
> 核心判断：斯大林人物关系页不是孤立页面，而是未来国际共运人物大星图的“恒星局部系统”先锋样板。

---

## 1. 总体目标

建设一个专门梳理国际共产主义运动人物关系的探索型星图系统。

它不只是传统关系图，也不是百科列表，而是一个可以从人物、时代、国家、组织、事件、路线和战士群像多入口进入的“历史星图”。

目标体验：

> 从一个人出发，进入一百五十余年的国际共产主义运动。

---

## 2. 为什么斯大林关系页可以作为先锋

斯大林专题关系页与未来大星图在抽象结构上是相似的。

如果把未来大图谱理解为宇宙，那么斯大林关系页就是一个局部恒星系：

| 星图隐喻 | 在斯大林关系页中的含义 | 未来大星图中的含义 |
|---|---|---|
| 恒星 | 斯大林本人 | 五大导师、国家革命核心人物、关键历史轴心人物 |
| 行星 | 老近卫军、政治执行者、军事班底、战时将领等直接关系人物 | 围绕核心人物运行的同党、战友、继承者、对手、组织者 |
| 彗星 | 托洛茨基等强冲突、强轨迹、跨系统分歧者 | 路线分化者、流亡者、跨国革命者、争议人物 |
| 小星星带 | 有名的人民群众、战士、烈士、文艺与宣传工作者 | C 类人物：战士、青年、作家、记者、翻译者、国际志愿者 |
| 卫星 | 与斯大林不直接相连、但与行星相连的人物 | 二跳关系、组织链、地区链、事件链中的外围人物 |
| 星云 | 苏联党政军、共产国际、卫国战争、后斯大林时期等关系场 | 国家、地区、组织、革命浪潮、思想路线与历史阶段 |

因此，斯大林关系页应承担以下探索任务：

1. 验证“恒星—行星—彗星—卫星—星云”的视觉语言是否成立。
2. 验证局部人物系统能否自然扩展到二跳、三跳关系。
3. 验证人物详情卡是否能同时容纳身份、时期、组织、事件、证据和争议。
4. 验证小人物如何在不喧宾夺主的情况下被高光。
5. 验证未来大星图的数据字段如何从局部页自然增长，而不是推倒重来。

## 3. 设计原则

### 3.1 星图优先，不做毛线团

人物数量增大后，不能把所有节点和线同时铺满。大星图应优先展示“星系结构”，再逐步展开局部关系。

原则：

- 默认看星系，不默认看全量细线。
- 先显示核心人物、星云区域、路线航线。
- 点击后再展开行星、卫星、小星星带。
- 线条分层显示：主航线常显，普通关系按需出现。

### 3.2 局部恒星系与全局宇宙同构

每个导师或关键人物的关系页，都应是大星图的局部切片。

局部页不应另起一套不可迁移的设计，而应使用和大星图相同的概念：

- 节点等级
- 轨道层级
- 关系类型
- 时间范围
- 组织/事件/地区字段
- 证据与争议字段
- 推荐探索路线

### 3.3 小人物必须能发光

大星图不能只服务领袖和国家领导人。战士、烈士、作家、记者、翻译者、国际志愿者、群众代表也应拥有位置。

设计上需要“小人物高光模式”：

- 平时作为星带或微光节点存在。
- 进入相关主题路线时被点亮。
- 人物卡解释他们如何连接历史主线。

### 3.4 争议不是噪音，而是图层

国际共运中的路线分歧、历史评价和复杂关系不能简单抹平。

争议应作为可开关图层：

- 默认克制显示。
- 打开后显示争议标记、不同评价角度、证据状态。
- 关系可以是多阶段、多方向、多强度，而非好坏二分。

## 4. 视觉方向

推荐整体视觉：

> 红黑金历史星图 + 纸质档案抽屉 + 抽象世界战略地图。

### 4.1 星图层

- 暗色模式下采用深红、黑褐、暗金、冷蓝。
- 亮色模式下采用羊皮纸、低饱和红、旧地图线条。
- 节点像星体，等级决定大小、光晕、常显程度。
- 关系线像轨道、航线或引力线。
- 星云用于表示国家、组织、革命区域、历史阶段或思想路线。

### 4.2 档案层

人物详情不做百科长文，而做档案抽屉：

- 一句话身份。
- 三到五个标签。
- 活跃时间。
- 国家/地区。
- 组织。
- 事件。
- 主要关系。
- 争议与证据。
- 推荐继续探索。

### 4.3 战略地图层

未来可加入地理视图：

- 欧洲/俄国。
- 中国/东亚。
- 拉美。
- 非洲。
- 中东。
- 东南亚。
- 国际流亡、会议、援助、战争、思想传播路线。

## 4.4 局部恒星系的空间语法定稿

斯大林测试版暴露出一个关键问题：如果所有对象都用 `r/a/z` 绕中心旋转，星云、小行星带、彗星、卫星最终都会退化成“带不同颜色的行星”，既不符合天体规律，也不利于梳理复杂关系。

后续大星图应采用分层渲染语法：

| 类型 | 现实规律 | 关系含义 | 视觉与交互规则 |
|---|---|---|---|
| 恒星 | 引力中心 | 局部系统核心人物 | 中央强光晕，可嵌肖像；不等同于价值崇拜，而是历史关系中心 |
| 行星 | 稳定环绕恒星 | 直接、长期、稳定关系人物 | 清晰轨道，大中型星体；只给老近卫军、政治执行者、军事班底、继承者等直接关系 |
| 卫星 | 环绕行星 | 与恒星间接相关，但与某个行星/系统明确相关 | 必须绑定 `parent`，绕父行星小轨道运行；点击父行星时可高亮卫星群 |
| 彗星 | 高偏心轨道，掠近后偏离 | 严重路线分歧、流亡、清洗争议或外部冲击 | 不走圆轨道；使用 `periapsis/apoapsis` 椭圆轨道；彗尾为背离恒星方向的粒子云，不画硬长条 |
| 小行星带 | 大量微小碎片形成环带 | 群众、劳动模范、英雄、战士、烈士、作家、左翼知识分子等群体层 | 以数百微光碎片形成带状区域；代表人物只是高亮矿点，避免把群众层做成孤立大人物 |
| 星云 | 大尺度气体尘埃场 | 历史事件、组织、战争、路线、时代背景 | 作为大面积半透明场域绘制，可点亮/筛选；不作为普通小球绕行 |
| 远轨天体 | 外层慢速轨道 | 后续历史遗产、继承与否定 | 冷色、稀疏、慢速，强调历史距离 |

数据层建议从普通节点字段升级为多种布局对象：

```js
// 稳定行星
{ id: 'molotov', type: 'planet', group: 'organization', orbit: { type: 'stellar', radius: 170, angle: 16, plane: -0.08, speed: 0.026 } }

// 卫星：必须绑定父行星
{ id: 'rokossovsky', type: 'moon', parent: 'zhukov', orbit: { type: 'satellite', radius: 52, angle: 130, speed: 0.055 } }

// 彗星：高偏心轨道
{ id: 'trotsky', type: 'comet', group: 'conflict', orbit: { type: 'comet', periapsis: 210, apoapsis: 650, angle: 184, tail: 'anti-star' } }

// 星云：区域，不是点
{ id: 'war-nebula', type: 'nebula', group: 'war', region: { angle: 58, distance: 510, width: 560, height: 330 } }

// 小行星带：群体层
{ id: 'people-belt', type: 'asteroidBelt', group: 'belt', inner: 405, outer: 505, count: 420 }
```

渲染器也应按层拆分：

1. `drawBackground()`：深空、基础星尘。
2. `drawNebulaRegions()`：历史星云场域。
3. `drawStellarOrbits()`：稳定行星轨道。
4. `drawCometOrbits()`：彗星高偏心虚线轨道。
5. `drawAsteroidBelts()`：群众小行星带。
6. `drawPlanets()` / `drawMentors()`：稳定天体。
7. `drawMoons()`：绑定父行星的小轨道。
8. `drawComets()`：柔和粒子彗尾。
9. `hitTest()`：星体、星云区域与星带高亮点分层命中。

这个规则比“所有节点一视同仁地画成点”更适合国际共运人物关系：稳定关系、间接关系、冲突关系、群众层和历史场域可以同时存在，却不会混成毛线团。

## 5. 节点等级与星体隐喻

| 等级 | 星体隐喻 | 人物类型 | 显示策略 |
|---|---|---|---|
| S | 恒星 | 马克思、恩格斯、列宁、斯大林、毛泽东等世界历史轴心人物 | 常显、大光晕、可作为局部系统中心 |
| A | 大行星/次恒星 | 国家革命核心人物、重要国际领袖、关键理论家 | 在相关星系常显，可成为二级中心 |
| B | 行星/彗星 | 组织者、军事家、路线斗争人物、争议人物、跨国活动家 | 按路线、时代、组织显示 |
| C | 小星星/星带 | 战士、烈士、作家、记者、青年革命者、国际志愿者 | 默认微光，主题路线中高光 |
| D | 卫星/碎片 | 二跳关系、亲属、短期协作者、局部事件人物 | 点击展开或搜索出现 |

注意：等级不是价值判断，而是图谱可读性权重。C/D 类人物在特定路线中可以临时升亮。

## 7. 核心探索功能

### 7.1 从这里出发

点击任意人物后提供：

- 看上游影响。
- 看下游影响。
- 看同代战友。
- 看路线敌手。
- 看关联国家。
- 看关联组织。
- 看关联文章/文献。

### 7.2 路径查找

允许用户输入两个节点，系统生成关系路径：

- 马克思 → 胡志明。
- 海明威 → 斯大林。
- 陈乔年 → 卡斯特罗。
- 列宁 → 金正日。

路径不只显示节点，还要解释每一步关系。

### 7.3 随机漫游

按钮：随机打开一条红色人物链。

示例：

- 马克思 → 拉法格 → 第二国际 → 列宁 → 共产国际 → 胡志明。
- 斯大林 → 季米特洛夫 → 反法西斯统一战线 → 国际纵队 → 海明威。
- 陈独秀 → 陈乔年 → 旅欧青年共产主义运动 → 周恩来 → 中国革命。

### 7.4 时间切片

用时间轴控制可见人物与关系：

- 1840s—1871：理论形成与第一国际。
- 1871—1914：第二国际与帝国主义时代。
- 1914—1924：一战、十月革命、共产国际成立。
- 1924—1953：社会主义建设、反法西斯战争、民族解放浪潮。
- 1953—1976：冷战、去斯大林化、中苏论战、第三世界革命。
- 1976—1991：修正主义危机与苏东剧变。
- 1991—至今：后社会主义时期。

### 7.5 路线/阵营图层

可切换：

- 马克思主义。
- 列宁主义。
- 斯大林时期社会主义建设路线。
- 托洛茨基主义。
- 铁托主义。
- 赫鲁晓夫修正主义。
- 毛泽东思想。
- 霍查主义。
- 古巴革命路线。
- 主体思想。
- 欧洲共产主义。
- 第三世界民族解放路线。

### 7.6 小人物高光模式

打开后：

- 大导师退为背景恒星。
- 战士、烈士、作家、记者、青年、翻译者、国际志愿者被点亮。
- 展示他们如何与主线连接。

## 10. 近期待办

### 第一轮：低保真探索与 Canvas 测试版（已完成）

1. 已画出斯大林局部恒星系的信息架构：恒星、行星、彗星、卫星、小行星带、星云。
2. 已选取并整理约 30 个斯大林局部节点，吸收 `relations.json` 的 group / rank / role / summary / organizations / events 等字段。
3. 已验证轻量 HUD、可隐藏控制台、搜索/路线筛选、右侧档案抽屉的基础体验。
4. 已发现旧路径的教训：若把所有对象都画成普通节点，星云、卫星、彗星、小行星带会退化成一堆行星。

### 第二轮：星系语法重构（已形成测试版）

1. 数据从单一 `r/a/z` 模型升级为多布局对象：`stellar`、`satellite`、`comet`、`nebula region`、`asteroidBelt`。
2. 卫星不再绕恒星，而是通过 `parent` 绑定父行星，例如罗科索夫斯基/科涅夫围绕朱可夫，外交人民委员部围绕莫洛托夫。
3. 彗星不再画硬长条，改为高偏心轨道与背离恒星方向的柔和粒子彗尾。
4. 星云不再作为小球节点，改为可点亮的大面积历史场域。
5. 小行星带不再是几个点，改为大量微光碎片组成的群众层，代表人物作为高亮矿点。
6. 分类按钮从“筛掉节点”升级为“点亮区域/图层”，更接近未来大星图的观察路线。

### 第三轮：迁回正式 Qmlmreader 页面

1. 将测试版的 Canvas 分层渲染迁入 `html/masters/stalin/relations.html` 或新组件，替换旧的二维放射图。
2. 保留 `data/masters/stalin/relations.json` 作为资料源，但扩展 orbit/region/belt 字段。
3. 把现有 CSS 的红黑金档案配色与测试版深空星云合并，避免 UI 喧宾夺主。
4. 增加“从这里出发”与“随机漫游”的轻量原型。
5. 档案抽屉继续规范化：身份、轨道、星云、组织、事件、争议、资料来源。

### 第四轮：全局大星图数据试建

1. 建立 `data/graph/` 草案。
2. 抽取 S/A/B/C/D 节点样例。
3. 抽取 3—5 条跨国路径样例。
4. 验证斯大林局部页能否成为全局图谱子集。
