# 个人偏好模块 README

> 对应源码：`html/preferences/preferences.html`、`js/preferences.js`、文章页注入入口。  
> 作用：承载本地收藏、阅读历史、视图设置预留与相关本地管理功能。

---

## 1. 页面范围

```text
html/preferences/preferences.html
```

---

## 2. 当前职责

| 功能 | 说明 |
|---|---|
| 收藏 | 本地保存文章收藏列表 |
| 阅读历史 | 保存最近阅读文章、Tab 与位置 |
| 视图设置 | 先保留接口，后续统一管理展示模式 |
| 数据管理 | 本地导出 / 导入 / 重置，不接后端 |
| 交互 | 左侧导航、搜索、刷新、单条删除、快速导出、文章卡片/详情页收藏按钮 |

---

## 3. 数据边界

| 键 | 用途 |
|---|---|
| `qmlm:preferences:v1` | 个人偏好总状态 |
| `favorites` | 收藏文章列表 |
| `history` | 阅读历史列表，最多保留 50 条 |
| `view.mode` | 展示模式预留 |
| `view.density` | 密度预留 |

---

## 4. 维护重点

1. 优先服务文章页的最小闭环，不要先扩散到全站所有模块。
2. 当前只做本地浏览器偏好，不引入后端同步。
3. 视图设置先留接口，等多个展示页统一改造时再接入具体切换逻辑。
4. 阅读历史要保留页面位置、Tab、章节等信息，方便“继续阅读”。
5. 数据管理区仅服务本地浏览器导入导出，作为轻量维护接口。
6. 页面视觉以现代卡片 + 轻玻璃质感为主，保持与站点整体红色主调一致。
7. 顶部概览统计优先反映本地状态，帮助用户快速判断偏好是否已保存。
