## 2. 视觉交互设计（暗房冲印红调风）【跳脱·现代化】

### 2.1 设计切入

照片处理 → 老式暗房/冲印工作台。暗房安全灯本身就是红色，天然呼应「红化」主题。走现代摄影工具美学。

### 2.2 色板（现代摄影工具，微红点缀）

| 角色 | 色值 |
|------|------|
| 暗房安全灯红（氛围） | `#ff3b30` |
| 深灰底（工作台） | `#1c1c1e` |
| 照片纸米白 | `#f5efe4` |
| 金属灰（面板） | `#3a3a3c` |

### 2.3 落地要点

- **元素**：取景框（四角 L 形 `border`）、对焦环、曝光参数面板。
- **交互**：拖入照片 → 参数滑块（红调强度/版画颗粒/剪纸化/对比度）→ 实时预览 → 导出。
- **氛围**：低照度红色环境光（`radial-gradient` 红晕）。
- **四种风格预设做成「冲印药水」按钮**：宣传画/版画/剪纸/招贴。
- **仍继承母站骨架**：导航、暗色模式、自定义光标。

## 3. 全流程

```
进入 → 上传照片
  → 选红化风格(宣传画/版画/剪纸/招贴)
  → 调参数(红调强度/版画颗粒/剪纸化/对比度)
  → [系统] chatGPT 生图重绘(保留人脸特征)
  → 预览 → 下载
  → (联动) 供图给青马立绘 / 小册子插图
```

| 步骤 | 用户动作 | 系统处理 | 界面呈现 |
|------|---------|---------|---------|
| 1 上传 | 拖入照片 | 读取原图 | 取景框预览 |
| 2 选风格 | 点「冲印药水」 | 载入风格预设 prompt | 药水按钮 |
| 3 调参 | 拉滑块 | 实时调 prompt 参数 | 参数面板 |
| 4 重绘 | 点「红化」 | 调 chatGPT 生图 | 加载态 |
| 5 导出 | 点下载 | 保存图片 | 下载 |
