# 文章页维护规范

> 作用：记录经典文章详情页的统一接口、变量、模板和常见错误。  
> 使用方式：任何新增、修复、重写文章页的任务，都必须先读本文和 `html/articles/_template-v2.html`。

---

## 一、标准文件位置

文章页位于：

```text
html/articles/{Author}/{slug}.html
```

作者目录当前包括：

- `Mao/`
- `Marx/`
- `Engels/`
- `Lenin/`
- `Stalin/`

模板文件：

```text
html/articles/_template-v2.html
```

公共样式：

```text
css/articles-detail.css
```

公共脚本：

```text
js/article-common.js
```

---

## 二、文章页必须引入的资源

文章页通常位于 `html/articles/{Author}/` 下，因此相对路径一般是三级返回：

```html
<link rel="stylesheet" href="../../../css/style.css">
<link rel="stylesheet" href="../../../css/articles-detail.css">
<script src="https://cdn.jsdelivr.net/npm/chart.js"></script>
```

底部脚本顺序：

```html
<script src="../../../js/article-common.js"></script>
<script>
    var ARTICLE_CHARTS = [...];
    var DOWNLOAD_LINKS = [...];
</script>
<script src="../../../js/site-data.js"></script>
<script src="../../../js/main.js"></script>
<script src="../../../js/darkmode.js"></script>
<script src="../../../js/cursor.js"></script>
```

关键点：

- `article-common.js` 必须在 `ARTICLE_CHARTS` 声明之前加载。
- `site-data.js` 必须在 `main.js` 之前加载。
- `Chart.js` 必须在使用 `ARTICLE_CHARTS` 的页面加载。

## 三、HTML 结构接口

文章页 `<body>` 必须有分类：

```html
<body data-category="philosophy">
```

取值范围：

- `philosophy`
- `economics`
- `politics`
- `party`
- `military`
- `culture`

导航占位：

```html
<div id="nav-placeholder"></div>
```

合集上下文导航：

```html
<div class="back-nav" style="display:none;">
    <div class="container" style="max-width:900px;margin:0 auto;padding:0 20px;">
        <a href="../../articles/articles.html" class="back-link"></a>
    </div>
</div>
```

文章主体容器：

```html
<main class="article-detail">
```

## 四、统一视觉变量

文章页必须在页面内覆盖三项分类变量：

```css
:root {
    --cat-primary: #8b0000;
    --cat-secondary: #c41e3a;
    --cat-gradient: linear-gradient(135deg, #4a0000 0%, #8b0000 50%, #c41e3a 100%);
}
```

分类建议：

| 分类 | data-category | 主色建议 |
|---|---|---|
| 哲学基础 | `philosophy` | 暗红 |
| 政治经济学 | `economics` | 深焦橙 |
| 政治理论 | `politics` | 深紫 |
| 党的建设 | `party` | 森林绿 |
| 军事战略 | `military` | 海军蓝 |
| 思想文化 | `culture` | 古金 |

维护规则：

- 页面内只写本文特有样式，不重复复制 `articles-detail.css` 里的公共组件样式。
- 所有公共组件颜色优先使用 `var(--cat-primary)`、`var(--cat-secondary)`、`var(--cat-gradient)`。

## 五、Tab 接口

文章页标准 7 个 Tab：

```html
<div class="tab-nav">
    <button class="tab-btn active" onclick="switchTab('original', this)">原文</button>
    <button class="tab-btn" onclick="switchTab('reading', this)">读法提示</button>
    <button class="tab-btn" onclick="switchTab('difficulty', this)">难点解析</button>
    <button class="tab-btn" onclick="switchTab('dialogue', this)">对话空间</button>
    <button class="tab-btn" onclick="switchTab('action', this)">行动实验</button>
    <button class="tab-btn" onclick="switchTab('visual', this)">一目了然</button>
    <button class="tab-btn" onclick="switchTab('puzzle', this)">理论拼图</button>
</div>
```

对应内容容器 ID：

- `original`
- `reading`
- `difficulty`
- `dialogue`
- `action`
- `visual`
- `puzzle`

公共函数来自 `js/article-common.js`：

- `switchTab(tabId, btn)`
- `toggleChapter(titleEl)`
- `toggleAllChapters()`

## 六、章节折叠接口

章节结构：

```html
<div class="chapter">
    <h3 class="chapter-title" onclick="toggleChapter(this)">
        <span class="toggle-icon"></span>
        章节标题
    </h3>
    <div class="chapter-content">
        <p>正文段落</p>
    </div>
</div>
```

全部展开/收起按钮：

```html
<button class="chapter-toggle-all" onclick="toggleAllChapters()" id="chapterToggleBtn">收起全部</button>
```

## 七、图表接口

图表统一通过 `ARTICLE_CHARTS` 声明，由 `article-common.js` 在切换到 `visual` Tab 时初始化。

```js
var ARTICLE_CHARTS = [
    {
        id: 'radarChart',
        config: {
            type: 'radar',
            data: {},
            options: {}
        }
    },
    {
        id: 'argumentCurve',
        config: {
            type: 'line',
            data: {},
            options: {}
        }
    }
];
```

必须存在的 canvas：

```html
<canvas id="radarChart"></canvas>
<canvas id="argumentCurve"></canvas>
```

硬规则：

- `ARTICLE_CHARTS[i].id` 必须和 `<canvas id="...">` 完全一致。
- 不要在页面里直接 `new Chart(...)`。
- 不要在隐藏 Tab 中提前初始化图表。
- `ARTICLE_CHARTS` 保持多行展开格式，便于维护和排错。

## 八、下载按钮接口

文章页使用统一下载浮动按钮，数据来自：

```js
var DOWNLOAD_LINKS = [
    { label: 'PDF 下载', href: '../../../downloads/articles/xxx.pdf' },
    { label: 'TXT 下载', href: '../../../data/xxx.txt' }
];
```

页面需要提供固定 DOM：

```html
<div class="download-fab" id="downloadFab">下载</div>
<div class="download-menu" id="downloadMenu">
    <div id="downloadLinks"></div>
</div>
```

`article-common.js` 会读取 `DOWNLOAD_LINKS` 并填充 `#downloadLinks`。

## 九、当前例外与风险

实测 29 个文章 HTML 中：

- `html/articles/Mao/shi-jian-lun.html` 缺少 `ARTICLE_CHARTS`、`DOWNLOAD_LINKS`、`article-common.js`。
- `html/articles/Mao/mao-dun-lun.html` 缺少 `ARTICLE_CHARTS`、`DOWNLOAD_LINKS`、`article-common.js`。

这两篇可能是早期基准页，但它们现在反而是模板统一的例外。后续建议专门迁移，避免新 AI 误以为它们仍是最新模板。

## 十、验收清单

新增或修改文章页后检查：

- [ ] 页面位于正确作者目录。
- [ ] `<body data-category="...">` 正确。
- [ ] `<main class="article-detail">` 存在。
- [ ] 7 个 Tab 与 ID 一一对应。
- [ ] 章节使用 `.chapter` / `.chapter-title` / `.chapter-content`。
- [ ] 图表 canvas 与 `ARTICLE_CHARTS` ID 完全一致。
- [ ] `DOWNLOAD_LINKS` 存在且路径可用。
- [ ] `site-data.js` 在 `main.js` 之前。
- [ ] 黑夜模式可读。
- [ ] 移动端 Tab 不溢出。
