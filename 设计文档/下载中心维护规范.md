# 下载中心维护规范

> 作用：记录下载中心的数据接口、文件路径和当前风险。  
> 使用方式：涉及 PDF、TXT、ZIP、下载页面、manifest 的任务先读本文。

---

## 一、页面与数据位置

页面：

```text
html/downloads/downloads.html
```

权威清单：

```text
downloads/manifest.unified.json
```

旧兼容清单：

```text
downloads/manifest.json
```

生成产物：

```text
js/site-data.js
```

同步脚本：

```bash
python _tools/sync_manifest.py
```

数据构建脚本：

```bash
python _tools/build_data.py --write
```

---

## 二、前端读取接口

`html/downloads/downloads.html` 当前先声明内嵌数组，再优先使用 `SITE_DATA` 覆盖：

```js
if (window.SITE_DATA && window.SITE_DATA.downloadData) {
    articlePDFs = window.SITE_DATA.downloadData.articles || [];
    rectifyPDFs = window.SITE_DATA.downloadData.rectify || [];
    posterZIPs = window.SITE_DATA.downloadData.posters || [];
}
```

渲染函数：

- `renderArticleCard(item)`
- `renderRectifyCard(item)`
- `renderPosterCard(item)`
- `esc(s)`

筛选依赖：

```html
<button class="dl-filter-btn" data-filter="mao">毛泽东</button>
```

卡片依赖：

```html
<div class="dl-card cat-mao" data-cat="mao">
```

## 三、文件路径规则

经典文章 PDF：

```text
downloads/articles/{slug}.pdf
```

正名文章 PDF：

```text
downloads/rectify/{slug}.pdf
```

宣传画 ZIP：

```text
downloads/posters/{file}
```

页面中对应 href：

```js
'../../downloads/articles/' + item.slug + '.pdf'
'../../downloads/rectify/' + item.slug + '.pdf'
'../../downloads/posters/' + item.file
```

## 四、manifest 字段

当前结构：

```json
{
  "articles": [
    { "title": "实践论", "author": "毛泽东", "cat": "mao", "slug": "shi-jian-lun", "year": 1937 }
  ],
  "rectify": [
    { "title": "...", "cat": "rectify", "slug": "rectify-stalin-era", "section": "leaders" }
  ],
  "posters": [
    { "label": "苏联宣传画·共青团", "size": "1.1 MB", "cat": "posters", "file": "soviet-posters-共青团.zip" }
  ]
}
```

建议后续扩展字段：

- `format`：`pdf`、`txt`、`zip`
- `quality`：`scan`、`text`、`ocr`
- `source`：来源说明
- `sizeBytes`：机器可读大小
- `relatedArticleSlug`：关联文章 slug

## 五、当前已发现问题

实测 `downloads/manifest.unified.json` 有 3 个 ZIP 指向不存在文件：

```text
downloads/posters/chinese-posters-V01.zip
downloads/posters/chinese-posters-V02.zip
downloads/posters/chinese-posters-V03.zip
```

需要确认：

- 文件是否未放入仓库；
- 文件是否在其他目录；
- 是否因为体积过大不应直接托管；
- 是否应该从下载中心暂时隐藏。

---

## 六、长期改造建议

1. 下载页删除内嵌 `articlePDFs`、`rectifyPDFs`、`posterZIPs`。
2. 下载数据只从 `downloads/manifest.unified.json` 进入 `site-data.js`。
3. `_tools/build_data.py` 增加下载文件存在性校验。
4. 下载中心显示资源质量：扫描版、文本版、OCR 版。
5. 单篇文章统一以 Word（docx/doc）为主要下载格式，著作类条目统一以 PDF 为主要下载格式。
6. 中国宣传画体积过大，优先采用百度网盘外链收纳，下载中心仅保留可点击链接与说明，不强行入仓。
7. TXT/PDF/Word/网盘外链统一建模，避免单一格式入口。
