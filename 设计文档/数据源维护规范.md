## 二、权威数据源

### 文章元数据

文件：

```text
data/articles.json
```

核心字段：

```json
{
  "slug": "shi-jian-lun",
  "title": "实践论",
  "author": "毛泽东",
  "authorKey": "mao",
  "date": "1937年7月",
  "year": "1937",
  "priority": 5,
  "category": "哲学基础",
  "type": "philosophy",
  "keywords": ["认识论", "辩证法", "实践"],
  "file": "articles/Mao/shi-jian-lun.html",
  "ready": true,
  "collections": ["mao-vol1", "mao-philosophy"]
}
```

合法取值：

- `authorKey`：`marx`、`engels`、`lenin`、`stalin`、`mao`
- `type`：`philosophy`、`economics`、`politics`、`party`、`military`、`culture`
- `priority`：1 到 5

### 合集数据

文件：

```text
data/collections.json
```

合集文章 slug 格式：

```json
"slug": "Mao/shi-jian-lun"
```

注意：合集 slug 带作者目录，`articles.json` 的 `slug` 不带作者目录，校验脚本会用最后一段匹配。

### 文艺与正名搜索数据

文件：

```text
data/gallery.json
data/rectify.json
```

这两类数据由 `_tools/build_data.py` 打包进 `site-data.js` 的：

```js
window.SITE_DATA.galleryIndex
window.SITE_DATA.rectifyIndex
```

### 下载数据

权威文件：

```text
downloads/manifest.unified.json
```

旧兼容文件：

```text
downloads/manifest.json
```

同步脚本：

```bash
python _tools/sync_manifest.py
```

重构方向：

- 单篇文章统一以 Word（docx/doc）作为主要下载格式。
- 著作类条目统一以 PDF 作为主要下载格式。
- 中国宣传画不再强制本地托管 ZIP，改为百度网盘外链入口。
- 下载数据模型后续应同时支持本地文件与外链链接。

## 三、生成产物接口

生成文件：

```text
js/site-data.js
```

生成函数：

```bash
python _tools/build_data.py --write
```

输出结构：

```js
window.SITE_DATA = {
  generatedAt: "by build_data.py",
  collections: [],
  articles: [],
  articleIndex: [],
  galleryIndex: [],
  rectifyIndex: [],
  downloadData: {}
};
```

不要手工编辑 `js/site-data.js`。

---

## 四、构建脚本职责

文件：

```text
_tools/build_data.py
```

读取：

- `data/articles.json`
- `data/collections.json`
- `data/gallery.json`
- `data/rectify.json`
- `downloads/manifest.unified.json`

校验：

- `ready: true` 文章是否有对应 HTML 文件
- `authorKey` 是否合法
- `type` 是否合法
- `priority` 是否合法
- `collections` 中引用的合集 ID 是否存在
- `collections.json` 中的文章 slug 是否能匹配 `articles.json`

生成：

- `js/site-data.js`

## 五、前端读取接口

### `main.js`

```js
if (window.SITE_DATA && window.SITE_DATA.collections) {
    COLLECTIONS = window.SITE_DATA.collections;
}
```

用途：合集上下文导航、合集弹窗、文章上/下一章。

### `search.js`

```js
var articleIndex = window.SITE_DATA.articleIndex;
var galleryIndex = window.SITE_DATA.galleryIndex;
var rectifyIndex = window.SITE_DATA.rectifyIndex;
```

用途：全站搜索。

### `downloads.html`

```js
articlePDFs = window.SITE_DATA.downloadData.articles || [];
rectifyPDFs = window.SITE_DATA.downloadData.rectify || [];
posterZIPs = window.SITE_DATA.downloadData.posters || [];
```

用途：下载中心渲染。

### `articles.html`

```js
collectionsData = window.SITE_DATA.collections;
```

用途：合集卡片与弹窗。
