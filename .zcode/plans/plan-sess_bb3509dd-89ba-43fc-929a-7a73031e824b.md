# 导航栏收起 ⇄ 悬浮球(全站公共壳功能)

## Context
沉浸式阅读/工具模块需要更多纵向空间。导航由 `js/main.js` 统一注入(`header.site-header`,sticky、约 72px、z-index 100),移动端已有汉堡菜单并接入 `QMLMState.ui.navOpen`。本功能给导航加"收起为可拖拽悬浮球"的能力:**全站记住状态、球可拖拽且记忆位置、点击球恢复导航**。用户已确认这三个交互决策。

## 实现方案(3 个代码文件 + 2 个文档,无新增文件)

### 1. `js/state-center.js` — ui 域持久化白名单
现状:`persist()`(约 213-228 行)只写 `preferences`+`theme` 两域到 `qmlm:state:v1`,`ui` 域纯内存。
- 新增白名单 `UI_PERSIST_KEYS = ['navCollapsed', 'navBallPos']`;
- `persist()` 把 `ui` 域中命中白名单的键并入同一个 state 对象写入;
- `hydrate()` 启动时把这两键从存储还原回 `ui` 域;
- 其余 `ui` 键(`navOpen`、`collectionModal`)仍为运行态,不受影响;跨标签页 storage 同步(425-430 行)自动生效。

### 2. `js/main.js` — 注入与逻辑
- **注入模板**(12-40 行)两处:
  - `.site-header-inner` 内、`hamburger-btn` 之后加收起按钮 `<button id="navCollapseBtn" class="nav-collapse-btn" aria-label="收起导航">`(收起符号用内联 SVG chevron-up,与暗色按钮视觉同级;桌面和移动端都显示);
  - `</header>` 后加 `<button id="navBall" class="nav-ball" aria-label="展开导航" hidden>☭</button>`(☭ 与 logo 呼应)。
- **无闪烁初始化**:IIFE 注入 header 后立即同步读 `localStorage['qmlm:state:v1']` 里的 `ui.navCollapsed`(state-center.js 是动态加载,早于 `qmlm:state-ready`),命中则直接给 body 加 `nav-collapsed` 类,避免刷新时导航闪现。
- **逻辑块**(DOMContentLoaded 内,复用 darkmode.js 的"读 get→订阅→dispatch"三段式):
  - `setCollapsed(v)`:切 `body.nav-collapsed`;收起时把 header 的 `margin-bottom` 置为 `-offsetHeight px`(sticky 元素收回占位,内容平滑上移);对 header 挂 ResizeObserver,收起状态下高度变化时同步负 margin(stellar-boot.js 同款模式);发布 `QMLMState.dispatch('ui/patch', { navCollapsed: v }, 'nav-collapse')`;
  - 订阅 `ui.navCollapsed` 与 `ui.navBallPos`(绑定时机:立即 + `qmlm:state-ready`,同 navOpen 的 main.js:380-381 模式),状态变化反向同步 DOM;
  - 悬浮球:**pointer 事件拖拽**(setPointerCapture,`touch-action:none`),位移阈值 6px 区分"拖拽"与"轻点":轻点→`setCollapsed(false)`;拖拽→实时更新 left/top 并 clamp 在视口内,松手发布 `ui/patch { navBallPos: {x,y} }`;restore 时 clamp 进当前视口,`resize` 时重新 clamp;
  - 与移动端互不冲突:收起时整个 header(含汉堡)隐藏,球是唯一入口,点击球恢复后汉堡/菜单逻辑照旧。

### 3. `css/style.css` — 样式(追加在 header 相关区域后,约 100 行)
- `.site-header` 补 `transition: transform .35s ease, margin-bottom .35s ease`(与现有 background 过渡合并,2441-2445 行处);`body.nav-collapsed .site-header { transform: translateY(-110%); pointer-events: none; }`;
- `.nav-collapse-btn`:与 `.hamburger-btn`(1558 行基础样式)同族的幽灵按钮,尺寸略小;
- `.nav-ball`:fixed 圆球 48px(≤768px 时 40px),品牌红渐变+☭ 白字+投影,z-index 9500(低于阅读进度条 12000、高于 dcn 999),`cursor:grab`/拖拽时 `grabbing` 并关过渡,hover 放大 1.06;暗色模式微调底色;`prefers-reduced-motion` 下关闭动画。
